## 구현 단계 기준 (v2 신규)

| 단계 | 의미 | 기준 |
| --- | --- | --- |
| **MVP** | 1~2주차 | 대표 사건 1건으로 랜딩 → 사전 판단 → 판결 → AI·실제 판결 → 비교가 끝까지 동작하는 데 꼭 필요한 것. AI 판결은 오프라인에서 생성·검수한 결과를 적재한다 |
| **확장** | 3~6주차 | 배포 전까지 붙일 것. AI 판결 생성 파이프라인, AI 비교 분석, 부가 UI |
| **이후** | 6주 이후 | 프로젝트 기간 안에 하지 않아도 되는 것 |
| **데이터** | 병행 | 개발 기능이 아니라 팀이 콘텐츠를 준비·검수하는 작업. 개발과 동시에 진행 |
