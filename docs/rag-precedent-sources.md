공통 주의:

- 판결문 자체는 저작권법 제7조에 따라 보호받지 못하는 저작물이다. 판시사항 · 판결요지 · 참조조문(대법원 작성)은 임베딩에 넣지 않고 **판결 본문만** 쓴다.
- 비식별화한 판결문은 가공본임을 표시한다(law.go.kr 약관의 변조 제공 금지).
- 출처는 "법제처 국가법령정보센터 / 대법원", "LBox Open (CC BY-NC 4.0)"으로 남긴다. 사용자 화면에는 기존 원칙대로 `source_org`만 쓴다.
- GitHub · Hugging Face의 다른 판례 모음(`legalize-kr/precedent-kr` 등)과 AI Hub 71723 · 71848은 law.go.kr 사본이라 새 수집처로 세지 않는다.

| 살인미수 | 29 |
| 강도살인 · 기타 | 4 |
| 주문 일부 무죄(표시만 하고 포함) | 20 |
| 본문에 "양형기준" 언급(기수 101건 중) | 74 |

기수 101건의 선고 시기:

| 시기 | 건수 | 비고 |
| --- | --- | --- |
| 2013~ | 67 | |
| 2010~12 | 13 | 2010. 4. 15. 이전 범행이면 개정 전 법정형 |
| 2009 | 2 | 양형기준 시행(2009. 7. 1.) 전후 확인 |
| ~2008 | 13 | 양형기준 없음 · 개정 전 법정형 |
| 미상 | 6 | LBox 본문에서 날짜를 못 찾음 |

> ⚠️ **모든 수치는 자동 판정이다.** 무죄 · 양형 이유 · 유형 · 중복은 본문 패턴과 문장 겹침으로 판정했다. 사람 확인 없이 전부 적재하므로(팀 결정, 2026-10-10) 판례 조건(8-1)에 맞지 않는 판례가 섞일 수 있다. 검색 점수 하한과 샘플 검색 확인으로 거른다.

판정 방법:

- **조건 통과**: 본문에 "양형의 이유"가 있고, 주문에 무죄만 있지 않고(징역 · 사형 · 무기 없이 무죄), 공소기각이 아닌 판결.
- **중복**: LBox ↔ law.go.kr는 본문 문장 겹침(12자 조각의 30% 이상), 판결공보 ↔ law.go.kr는 사건번호, 판결공보 ↔ LBox는 판시사항 문장 겹침.
- **사건 그룹**: 범죄사실 문장이 20% 이상 겹치는 판결을 같은 사건으로 묶었다.

## 5. 기간을 넓혀서 생기는 표시 항목

판례마다 아래를 기록한다. 검색 때 같은 조건의 판례를 우선하거나 거른다.

| 항목 | 내용 |
| --- | --- |
| 사건 발생일 | 판결문의 범죄사실에서 찾는다. 양형기준 버전 판단 근거 |
| 적용 양형기준 버전 | 살인범죄 양형기준은 2009. 7. 1. 처음 시행됐다. 그 전 사건은 "없음"으로 둔다. 지금은 사건 발생일로 정하지만(ERD `legal_case.incident_date`), 양형기준은 시행일 이후 **공소제기된** 사건에 적용하는 것으로 알고 있어 확인이 필요하다(6장) |
| 법정형 개정 전후 | 2010. 4. 15. 형법 개정으로 유기징역 상한이 15년에서 30년으로 올랐다. 개정 전 범행은 형량이 낮게 나오므로 표시한다 |
| 사건 그룹 | 같은 사건의 1심 · 항소심을 묶는다. 검색 결과에 같은 사건이 두 번 나오지 않게 한다 |
| 경합범 · 부인 · 미확정 · 일부 무죄 | 표시만 하고 포함한다(8-1) |
| 출처 | law.go.kr / LBox Open. 출처 표기와 라이선스 확인에 쓴다 |
