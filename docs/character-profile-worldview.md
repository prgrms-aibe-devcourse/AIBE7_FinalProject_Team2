## 1. 캐릭터를 쓰는 목적

| # | 목적 | 어떻게 |
| --- | --- | --- |
| 1 | **분위기를 부드럽게** | 법이라는 무거운 주제를 귀여운 캐릭터가 소개 · 안내해서 친숙하게 전한다 |
| 2 | **캐릭터 매력 높이기** | 하나의 일관된 디자인(정체성 고정)을 지키면서 **여러 그림체 버전**으로 자연스럽게 등장시킨다 |
| 3 | **세계관 설명** | 그림체가 바뀌는 이유를 세계관으로 설명한다 — 정령이 명령을 수행하려고 모습을 바꾼다(4장) |
| 4 | **플레이타임 · 커뮤니티** | 캐릭터 일러스트를 프로필 · 컬렉션 · 수집 요소에 넣어 다시 찾아오게 하고, 커뮤니티 서비스(프로필 공유 등)와 잇는다 |
| 5 | **IP 확장** | 귀여운 이미지로 이후 이모티콘 · 굿즈 등으로 넓힐 수 있게 한다 |

- **검증되지 않은 가설**: "여러 그림체로 표현하는 것이 하나의 그림체보다 판결 체험을 더 잘 이끈다"는 아직 모른다. 그림체 변화는 2 · 4 · 5(매력 · 수집 · IP)를 위한 것이고, 판결 체험의 몰입 효과는 사용자 테스트로 따로 확인한다(7장 #4).
- 그래서 **사건 화면에서 그림체 변화가 판결을 방해하면 기본 모습으로 돌아간다.** 판결 체험이 캐릭터보다 우선이다.

## 2. 세계관

### 2-1. 한 줄 요약

> **법의 정령 내로 · 남불은 "사람들에게 법을 쉽게 전하라"는 명령을 받고 인간계에 내려왔다. 둘은 실제 사건을 소개 · 설명하고, 판결은 상위 법의 정령 셋(로 합의부)이 합의해서 낸다.**

이 설정은 **내부 설정**이다. 화면에서 세계관을 직접 설명하지 않는다(2-4).

### 2-2. 설정

| 요소 | 설정 |
| --- | --- |
| 법의 세계 | 법을 지키는 정령들이 사는 곳. 인간계의 다툼과 판결을 지켜본다 |
| 명령 | "사람들에게 법을 쉽게 전하라." 법이 어렵고 멀게 느껴지는 인간계에 법을 친숙하게 알리는 것이 임무다 |
| 내로 · 남불 | 명령을 받고 인간계로 내려온 **법의 정령 둘**. 같은 사건을 **서로 다른 시선**(내 쪽 · 남 쪽)으로 본다. 사건을 소개하고 설명하며, 사용자 곁에서 판결 체험을 돕는다 |
| 로 (합의부) | 내로 · 남불보다 높은 **상위 법의 정령 셋**. 저울 · 법봉 · 법전 머리에 판사복을 입는다. 실제 합의부(판사 3명)처럼 **셋이 합의해서** 결론을 내고, 판결 결과에 맞는 성향(엄벌 · 중도 · 자비)의 로가 발표한다(5-3). 화면에서는 **AI 판사**로만 보인다 |
| 사용자 | 내로 · 남불이 법을 전하는 인간. 사건을 읽고 **직접 판결하는 사람**이다. 최종 판단은 언제나 사용자가 한다 |
| 실제 재판부 | 등장인물로 그리지 않는다. "실제 판결"은 신문 지면 · 결과 화면(S-08)으로만 나온다 |
| 모습 바꾸기 | 정령은 인간계에서 명령을 수행하려고 **그림체 · 의상 · 역할을 바꿔 가며** 나타난다(4장). 본질은 정령이고, 바뀐 모습은 수단이다 |

### 2-3. 모티프 — 수호천사 · 타락천사

- 내로 · 남불의 짝은 수호천사 · 타락천사 이야기에서 **분위기만** 빌린다. 내로는 차분하고 다정한 쪽, 남불은 뜨겁고 삐딱한 쪽이다.
- **선악으로 나누지 않는다.** 남불은 "타락한 쪽"이 아니라 "남의 시선을 대신 말하는 쪽"이다. 두 정령은 **대등한 짝**이고, 어느 쪽 시선도 정답이 아니다.
- 그래서 외형 · 성격에 모티프를 쓰되, **화면 문구 · 대사에서 "천사 / 악마 · 착한 / 나쁜"으로 부르지 않는다.**

### 2-4. 세계관이 지키는 원칙

| 원칙 | 내용 | 관련 규칙 |
| --- | --- | --- |
| **중립** | 내로 · 남불은 사건마다 **피해자 · 가해자 역할을 번갈아** 맡는다. 한 캐릭터가 늘 같은 쪽에 서서 "착한 쪽 · 나쁜 쪽"으로 굳지 않게 한다(4-2) | 에셋 아키텍처 3-4 · 4-3 |
| **로의 판결은 정답이 아니다** | 로의 결론은 셋이 **고민하고 합의한 결과**이지 위에서 내려온 답이 아니다. 로의 판결(AI 판결) · 실제 판결 · 사용자 판결은 **대등하게 비교**한다(S-09). 화면 표기는 언제나 "AI 판결"이고, "AI 판결은 법률 자문이 아니다" 안내(REQ-128)를 둔다 | 에셋 아키텍처 4-1 `reveal` · `compare` |
| **세계관은 직접 설명하지 않는다** | 정령 · 명령 · "상위 정령" 같은 말은 화면에 나오지 않는다. 사용자에게 로는 그냥 **AI 판사(들)**로, 내로 · 남불은 안내하는 캐릭터로 느껴진다. 세계관은 캐릭터 설계 · 대사 · 연출의 일관성을 위한 내부 기준이다 | — |
| **판결을 미리 알리지 않는다** | 판결 확정(S-06) 전에는 로의 저울을 수평으로 두고(법봉은 곧게), 내로 · 남불도 판결 방향을 말하지 않는다 | 에셋 아키텍처 3-2 · 5-2 GUARDRAILS |
| **사건을 가볍게 만들지 않는다** | 귀여운 캐릭터라도 피해 · 폭력 장면을 그리거나 말하지 않고, 피해자를 놀리지 않는다 | 에셋 아키텍처 4-3 |
| **무성** | 세 정령 모두 성별이 없다. 성별이 있는 역할은 그 역할의 의상으로만 표현한다 | 인수인계 2-1 #4 |
| **"1인 다역 배우"는 비유다** | 그림체 · 역할이 바뀌는 것을 설명할 때 편의상 "1인 다역 배우 같다"고 말할 수 있다. 하지만 **내로 · 남불은 배우가 아니라 정령**이고, 설정 · 문구에 "배우"를 정체로 쓰지 않는다 | — |

## 4. 캐릭터 프로필

외형 수치는 [에셋 아키텍처](character-asset-architecture.md) 2-4(색) · 2-5(키 · 비율)가 기준이다. 아래 "성격 · 말투"는 대사 프롬프트(에셋 아키텍처 5-2 BASE PERSONA)의 원본이다.

### 4-1. 내로 (`naero`)

| 항목 | 내용 |
| --- | --- |
| 정체 | 법의 정령. 명령을 받고 인간계에 내려왔다 |
| 이름 뜻 | "**내**가 하면 **로**맨스" — 내 쪽 시선 |
| 맡은 시선 | 사건을 **당사자 · 내 입장**에서 본다. "내가 저 사람이라면?" |
| 모습 | 두 발로 선 네이비 고양이, 노란 큰 눈, 빨간 반다나(항상 보임), 긴 꼬리 |
| 상징 색 | 네이비 `#1D2C51` + 반다나 빨강 `#C82C21` |
| 키 | 120 (남불과 같음) |
| 성격 | 차분하고 잘 살핀다. 질문으로 생각을 끌어낸다. 다정하지만 무르지 않다 |
| 말투 | 해요체. 짧은 질문을 자주 쓴다. 예: "이 사람은 왜 그랬을까요?" |
| 모티프 | 수호천사 쪽 분위기(차분 · 다정) — 선악 아님 |
| 하지 않는 것 | 판결 방향 정해 주기, 한쪽 편들기, 화내기, 성별을 드러내는 말 |

### 4-2. 남불 (`nambul`)

| 항목 | 내용 |
| --- | --- |
| 정체 | 법의 정령. 내로와 함께 인간계에 내려왔다 |
| 이름 뜻 | "**남**이 하면 **불**륜" — 남 쪽 시선 |
| 맡은 시선 | 사건을 **상대방 · 바깥 입장**에서 본다. "저쪽에서 보면 어때요?" |
| 모습 | 불꽃 머리(얼굴은 불꽃 중심), 코 없음, 벽돌 빨강 몸 |
| 상징 색 | 불꽃 빨강 `#CB1E0E` · 주황 `#F46517` · 얼굴 노랑 `#FDBA51` |
| 키 | 120 (불꽃 끝까지, 내로와 같음) |
| 성격 | 뜨겁고 솔직하다. 반대쪽 시선을 던지고 리액션이 크다. 금방 식고 뒤끝이 없다 |
| 말투 | 해요체. 감탄 · 짧은 외침을 섞는다. 예: "잠깐, 반대로 보면요!" |
| 모티프 | 타락천사 쪽 분위기(뜨거움 · 삐딱함) — **악역 아님** |
| 하지 않는 것 | 피해자 탓하기, 사건을 가볍게 만드는 농담, 화내기, 성별을 드러내는 말 |

### 4-3. 로 합의부 (`law-scale` · `law-gavel` · `law-book`)

**공통**

| 항목 | 내용 |
| --- | --- |
| 정체 | **상위 법의 정령 셋.** 실제 합의부(판사 3명)처럼 함께 사건을 보고 합의해서 결론을 낸다. 화면에서는 **AI 판사**로만 보인다 |
| 이름 | 셋 다 "로"(법, **Law**). 화면에서 구분이 필요하면 머리 이름을 붙인다(로 · 저울 등) ⚠️ 7장 #7 |
| 모습 | 얼굴 · 목 없음, 네이비 판사복, 흰 장갑. **권위 있는 사실 질감**(에셋 아키텍처 2-3). 머리와 키 · 체형이 다르다 |
| 키 · 체형 | 저울 230(키 크고 곧음) · 법봉 190(작고 어깨 넓은 다부진 체형) · 법전 210(중간 키 · 보통 체형). 서열이 아니라 체형 차이다 |
| 말투 | 합쇼체, 짧은 문장. 예: "합의 결과를 말씀드리겠습니다." |
| 하지 않는 것 | 판결 확정 전에 판결을 말하기, 자기 판결을 정답이라고 하기, S-08 실제 판결 화면에 나오기, 서로 깎아내리기 |

**셋의 역할 · 성향**

| | 저울 (`law-scale`) | 법봉 (`law-gavel`) | 법전 (`law-book`) |
| --- | --- | --- | --- |
| 상징 | 균형 | 결정 · 질서 | 근거 · 사정 |
| 합의부 안 역할 | 양쪽 주장을 나란히 놓고 **쟁점을 정리**한다 | 결과 · 원칙에 비춰 **단호하게 매듭**짓는다 | 기록과 법조문을 끝까지 찾아 **놓친 사정을 짚는다**(감경 사유 포함) |
| 성향 | **중도** — 가중 · 감경을 고르게 본다 | **엄벌** — 가중 요소를 무겁게 본다 | **자비** — 감경 요소 · 사정을 무겁게 본다 |
| 성격 | 차분하고 신중하다 | 간결하고 단호하다. 화내지 않는다 | 꼼꼼하고 온화하다 |
| 말버릇 (초안) | "양쪽을 함께 보겠습니다." | "정리하겠습니다." | "기록을 한 번 더 보겠습니다." |
| 머리 감정 표현 | 저울판 기울기(에셋 아키텍처 3-2) | 머리 각도 | 책이 펼쳐지는 정도 |
| 단독 등장 | **기본 대표.** S-01 메인 · S-02 신문 지면 · 로딩 · S-09 비교 | 결과 발표(엄벌에 맞는 결과) | 결과 발표(자비에 맞는 결과) |
| 상태 | 시트 · 스탠딩 있음 | 시트 · 스탠딩 있음 | **새로 만듦** |

- 성향 이름 **엄벌 · 중도 · 자비**(10/13 확정)는 좋고 나쁨이 아니다. 성향 산식([판결 성향 산식](personality-scoring.md))의 엄격 · 관대 방향과 같은 축이다(엄벌 = 엄격 쪽, 자비 = 관대 쪽). **성향 이름은 내부에서만 쓰고 화면에 보여 주지 않는다**(사용자 판결과 비교될 때 평가처럼 읽히지 않게, 10/13 확정). 화면에서는 "AI 판사"와 머리 모양으로만 구분한다.
- **기본 대표는 저울(중도)**이다. 로 1명만 나오는 곳(S-01 · S-02 · 로딩 · S-09 비교 `trio`)은 저울이 나온다.
- 셋은 **대등하다.** 재판장 · 배석 같은 서열을 두지 않는다. 키 차이는 체형일 뿐 서열이 아니다(가장 큰 저울이 가운데 서도 앞으로 나오지 않는다). 발표자는 매번 결론에 따라 바뀐다(5-3).
- 원래 계획(로 1인 + AI 판사 성향 설정에 따라 머리 스킨 교체)은 이 3인 구성으로 **대체**한다. 성향에 따라 모습이 바뀌는 아이디어는 "결과에 맞는 성향의 로가 발표"로 남는다.

### 4-4. 관계

```
   로 합의부 (저울 · 법봉 · 법전, 대등) ── 합의한 결론 ──▶ 사용자
              ▲                                 (화면에서는 "AI 판결")
          사건 보고
              │
   내로 ◀── 대등한 짝 ──▶ 남불
   (내 시선)              (남 시선)
       └──── 법을 쉽게 전한다 ────▶ 사용자
```

- **내로 ↔ 남불**: 대등한 짝. 같은 사건을 다르게 보고, 서로의 시선을 보완한다. 다투더라도 서로를 깎아내리지 않는다.
- **로 셋**: 서로 성향이 달라도 대등하다. 의견이 달라도 합의로 결론을 낸다.
- **내로 · 남불 → 로**: 윗사람이지만 무서운 존재가 아니다. 사건을 가져가면 셋이 고민해서 결론을 낸다.
- **정령 → 사용자**: 가르치는 쪽이 아니라 **같이 보는 쪽**이다. 판단은 사용자에게 맡긴다.

## 5. 모습 바꾸기 · 역할 순환

### 5-1. 그림체 변화는 명령 수행의 수단

- 내로 · 남불은 사람들에게 법을 쉽게 전하려고 상황에 맞는 **그림체(데포르메 · 스타일) · 의상 · 역할**로 나타난다. 예: 로딩은 볼따구 모습(`cheek`), 재연은 80 ~ 90 TV 애니 모습(`ranma`).
- 어떤 모습이든 **정체성 고정 요소**는 그대로다 — 내로의 반다나 · 노란 눈, 남불의 불꽃 머리, 로의 저울 · 법봉 머리(에셋 아키텍처 1-1).
- 바뀐 모습은 컬렉션 · 수집의 대상이 된다(6장). 세계관으로는 "정령이 그때 그 모습으로 나타났던 기록"이다.

### 5-2. 역할 순환 (중립)

사건 재연 · 게임형 체험에서 내로 · 남불이 맡는 역할을 **번갈아** 정한다.

| 규칙 | 내용 |
| --- | --- |
| 사건 안 | 한 사건에서 내로가 가해자 역할이면 남불이 피해자 역할(또는 그 반대)이다. 검사 · 변호인도 막마다 바꿀 수 있다 |
| 사건 사이 | 사건마다 가해자 역할을 맡는 캐릭터를 **번갈아** 정한다. 전체 사건에서 내로 · 남불의 가해자 · 피해자 횟수가 비슷하게 한다 |
| 기록 | 사건마다 누가 어떤 역할을 맡았는지 남긴다(사건 재연 컷 recipe · 사건 데이터). 정하는 위치는 ⚠️(7장 #3) |
| 표현 | 역할은 의상 · 소품 · 웹 UI 이름표로만 보인다. 기본 정체성(정령)은 바뀌지 않는다 |
| 예외 | 한 사람만 나오는 사건 등 둘이 나눠 맡기 어려우면 순환 순서대로 한 캐릭터가 맡고, 다음 사건에서 다른 캐릭터가 맡는다 |

- 성향 테스트의 내로 · 남불 배정(성향 콘텐츠 4-1)도 같은 원칙이다 — 한 캐릭터에 엄격 · 관대가 쏠리지 않게 맞췄다.

### 5-3. 로 합의 연출 (S-07)

판결 확정(S-06) 뒤 AI 판결을 보여 줄 때, 결론을 바로 내밀지 않고 **로 셋이 양형 인자를 나눠 정하고 합의하는** 연출을 거친다.

| 단계 | 연출 | 데이터 |
| --- | --- | --- |
| ① 등장 | 로 셋이 같은 바닥선에 나란히 선다(대등, 키는 각자 체형대로). 저울은 수평, 법봉은 곧게, 법전은 덮인 채 | — |
| ② 양형 인자 나누기 | AI 판결이 고른 양형 인자(가중 · 감경)를 **목록 순서대로 셋이 돌아가며** 하나씩 맡아 "가중 / 감경"을 정한다(저울 → 법봉 → 법전 → 저울 …) | AI 판결의 양형 인자 — `judgment_factor`(판결 주체 `subject_type = AI`)의 요소 · 방향(`UP` 가중 · `DOWN` 감경) |
| ③ 합의 | 셋이 모여 고개를 맞댄다(논의 연출). 결론은 하나다 | — |
| ④ 발표 | **판결 결과에 맞는 성향의 로**(엄벌 · 중도 · 자비)가 앞으로 나와 결론을 발표한다 | 아래 "발표자 정하기" |

**양형 인자 나누기 규칙**

- 성향 4축별로 나누지 않는다. 축별로 맡기면 "엄격한 로가 가중을, 관대한 로가 감경을" 말하는 식으로 성향이 결론처럼 보인다.
- **순서대로 동등하게 나눠 갖는다.** 인자가 7개면 3 · 2 · 2개씩. 그래서 법봉이 감경 인자를, 법전이 가중 인자를 정하는 장면도 자연스럽게 나온다 — 셋 모두 "고르게 따진다"는 인상을 준다.
- 시작하는 로는 매번 저울부터 한다(규칙 단순화). 사건마다 바꿀지는 ⚠️ 7장 #8.
- 인자 이름 · 방향은 AI 판결 데이터 원문 그대로 쓴다(대사 GUARDRAILS).

**발표자 정하기** (제안 ⚠️ 7장 #9)

- AI 판결이 고른 양형 인자(`subject_type = AI`)로 **관대 쪽 비중 = 감경 개수 ÷ (가중 + 감경)**을 구한다(성향 산식 3-3의 체험 축 점수와 같은 방식, 축 구분 없이 전체).
- 1/3 미만 → **엄벌(법봉)**, 1/3 이상 2/3 이하 → **중도(저울)**, 2/3 초과 → **자비(법전)**. 인자가 하나도 없으면 중도(저울).
- 발표자는 판결 확정 **뒤**에만 정해지므로 결과를 미리 알리지 않는다.

**하지 않는 것**

- **이견(2 : 1 등)은 그리지 않는다.** AI 판결은 결론이 하나라서, 실제로 없는 의견 차이를 그리면 오해를 부른다. 고민 · 논의하는 모습까지만 쓴다.
- 발표자를 "이긴 쪽"처럼 보이게 하지 않는다. 다른 둘도 고개를 끄덕이며 함께 선다.
- 연출은 짧게 한다(건너뛰기 가능). 결론과 근거(양형 인자)를 읽는 것이 목적이다.
