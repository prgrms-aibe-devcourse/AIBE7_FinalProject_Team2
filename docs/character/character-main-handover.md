## 3. 디자인 가이드 요약 (기획문서/14 v1.2)

- **변하는 것은 6가지뿐**: 동물 종 · 고유 특징, 표정, 자세, 소품 하나, 동물 고유 색 · 무늬, 대표색(넥타이 · 소품)
- **법복(변경 금지)**: 짙은 네이비 무광 펠트, 발목 위 기장(발만 보임), 깊은 V자 여밈, **같은 폭 앞단 두 줄이 목부터 밑단까지**, 밑단 가운데 닫힘, 넓은 나팔 소매, **주름 · 플리츠 없음**
- **셔츠 · 넥타이**: 따뜻한 흰 셔츠, 넥타이는 대표색 · 무광 · 무늬 없음
- **얼굴**: 단순한 둥근 눈 + 하이라이트, 짧은 눈썹(성향 표현의 핵심), 종에 맞는 작은 코, 작은 미소(치아 노출 금지)
- **관용 지수별 표정**

  | 관용 지수 | 눈썹 | 입 | 고개 |
  | --- | --- | --- | --- |
  | 4 | 편안하게 살짝 올라감 | 온화한 미소 | 살짝 기울임 |
  | 3 | 편안함 | 부드러운 미소 | 아주 살짝 기울임 |
  | 2 | 수평 | 작은 미소 | 반듯 |
  | 1 | 안쪽이 아주 살짝 내려감 | 작은 미소 | 반듯 |
  | 0 | 안쪽이 살짝 내려감 | 절제된 미소 | 반듯, 상체 곧게 |

- **소품**: 하나, 머리 너비의 25 ~ 40%, 얼굴보다 강조하지 않음, 법복 V자 · 넥타이가 보이게
- **자세**: 두 발을 바닥에 붙인 선 자세. 달리기 · 점프 · 앉기 · 팔 높이 들기 금지

### 5-2. 이미지 생성 방법 (GPT 이미지 생성 기준)

> ⚠️ **기록용(비활성)**: 아래는 동물 16종 · 소프트 3D · 2.5등신 방식이다(2-1 #1 · #2로 대체). 지금 제작 기준은 [캐릭터 에셋 아키텍처](character-asset-architecture.md)다.

1. **새 대화**에서 확정 이미지 두 장(`ESTJ_lion` · `INFP_panda` 원본)을 첨부하고 아래 공통 지시를 보낸다
2. 이후 메시지마다 **한 마리씩** 요청한다(한 장에 여러 마리를 그리면 특징이 섞인다 — 실제로 겪음)
3. 3 ~ 4마리 뒤 법복이 흐트러지거나, 부분 수정이 두 번 연속 안 먹히면 새 대화로 다시 시작한다
4. 받으면 6장 체크리스트로 검수한다

공통 지시 (요약본 — 전문은 가이드 9장):

```
첨부한 판다와 사자는 확정 캐릭터다. 같은 세계관 · 그림체 · 의상으로 새 캐릭터를 한 마리씩 만든다.
- 소프트 3D, 매끈한 무광 점토, 은은한 스튜디오 조명, 약 2.5등신 전신, 아이보리 단색 배경, 세로 4:5
- 짙은 네이비 법복: 깊은 V넥, 같은 폭 앞단 두 줄이 밑단까지, 앞이 닫힌 발목 기장 밑단, 넓은 나팔 소매, 주름 · 플리츠 없음
- 흰 셔츠, 넥타이는 대표색. 소품 하나를 넥타이와 같은 대표색 무광 점토로(금속 아님)
- 동물의 검은 부분은 네이비. 텍스트 · 로고 · 배지 · 추가 액세서리 · 배경 소품 · 두 마리 이상 금지
```

### 5-4. S-01 메인

- **물건 열기**: `frontend/src/pages/landing/landingPage.js`의 `OBJECTS`에서 `folder.route`에 S-15 화면 이름, `phone.route`에 S-17 화면 이름(`app/routes.js`의 `name`)만 넣으면 메모지 문구와 누르기 가능 여부가 함께 바뀐다
- **신문 지면**은 API 1(사건 목록)로 채운다. 목록 첫 사건(참여 많은 순)이 머리기사다. 기사(`headline` · `deck` · `article`)는 API 1에 아직 없는 제안 필드라, 실제 API로 바꾸면 기본 문구로 나온다
- **처음 판단 전 화면**이라 기사 · 노트북 말풍선에 S-04 이후 공개 사실(다툼 기간 · 횟수 · 양형 요소 · 판결 결과)을 쓰지 않는다(#101 리뷰)
- 색은 `style.css` ④ `--color-desk-*`만 쓴다. 손글씨 글꼴 `--font-hand`(나눔펜)
- 신문 흐름(2-1 #6 결정): 신문을 누르면 집어 드는 연출 뒤 S-02 신문 지면으로 이동하고, 기사를 고르면 사건 디테일을 거쳐 체험을 시작한다. 구현은 별도 이슈이며 지금 코드는 바로 이동한다. 연출은 C안 v4 시안의 `pick` 코드를 참고한다
- `ResizeObserver`는 화면을 떠난 뒤 다음 resize 때 끊긴다(영향 작음). 라우터에 화면 정리 단계가 생기면 거기로 옮긴다

### 5-5. S-02와의 관계 (D 정민석)
