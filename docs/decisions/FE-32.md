# FE-32 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #152 본문. 후속 썸네일 결정은 `BE-78.md`.

## 문제 / 배경
- 메인 책상 → 신문(S-02) → 사건 정보(S-20) → 판결 체험을 하나의 연속된 세계로 이어야 했다.

## 선택한 방법과 이유
- S-20을 1 · 2막 신문 지면(3면 기사 면)으로 삼았다. 대본이 있는 사건은 사건 정보 화면이 곧 1막이고, 시작 버튼으로 캐릭터가 등장한다. 대본이 없는 사건은 단순 상세 화면으로 남긴다(전 사건 대본 제작은 FE-33, 낮은 우선순위).
- 판결 체험 전체(1 ~ 8막)를 "신문 · 종이" 세계로 통일했다: 만평 말풍선 대사, 잉크 선 법정 스케치, 클립 끼운 서류 카드. 8막은 무대 상자 없이 화면 전체가 카메라 틀이다.
- 2막 사전 판단은 독자 의견 엽서 팝업(`role=dialog` + 뒤 지면 `inert`)으로 받고, 8막에서 "뉴스로 봤을 때" 칸으로 되돌려 보여 준다.
- 대본 규칙: 한 사건 안에서 같은 배역은 한 캐릭터만 맡는다(내로 = 검사 · 판사, 남불 = 변호인 · 피고인). 규칙 테스트를 추가했다.
- 접근성 · 모바일: 터치 대상 44px, 호버는 `(hover: hover)`에서만, 움직임 줄이기는 움직임 대신 0.2초 페이드, `viewport-fit=cover` + 안전 영역.

## 고려한 제약 사항
- 진행 중 체험의 보낸 판단을 서버에서 다시 읽을 API가 없어 브라우저 `localStorage` 값으로 보여 준다. 다른 기기에서는 안내만 나온다(필요하면 API 3 응답에 사전 판단 추가를 백엔드와 논의).
- 사진 없는 사건은 공용 재연 컷 3장을 돌려 쓴다.
- 예상 소요 · 난이도 표시는 팀 합의로 제거했다.
- 실기기 확인(터치 힌트, 모바일 엽서 제출 줄, 아이폰 노치, 신문 그림자 성능)은 남았고 FE-36으로 분리했다.

## 추후 재검토가 필요하면
- 전반적인 디자인 정리("AI 느낌" 제거)는 8막 완성 후 따로 진행하기로 했다.
