# FE-160 의사결정 기록

## 문제 / 배경
- FE-151(전 페이지 모바일 390px 대응)에서 범위 밖으로 넘긴 태블릿 구간(721 ~ 1000px) 문제 네 가지(FE-155 · FE-154 보고, DESIGN.md "현재 코드와 차이" 25번).
- 먼저 폭별로 재 보니 이슈에 적은 "1막 · 6막 신문 글자 8 ~ 11.5px"는 6막 **읽기 지면**("여기 남아있기" 뒤 신문 전체)과 같은 틀의 **내 결과 지면**의 문제였다.
  - 6막 읽기 지면: 721px에서 본문 9.3px · 표 머리 7px, 글자 100개 중 57개가 12px 미만. `--u = min(10px, (100vw − 32px) / 118)`이라 지면 전체가 화면 폭에 비례해 줄어든다.
  - 1막 지면은 모든 폭에서 가장 작은 글자 11.8px · 중간값 13px라 문제 없었다. 6막 카메라 장면은 초점이 맞은 칸은 읽히고, 작은 글자는 흐리게 가린 배경 지면이었다.
- 나머지 셋: 사건 목록 1면 머리기사(721 ~ 900px에서 기사 단 약 200px, 사진이 세로로 길게 늘어남), 성향 테스트 면 16유형 갤러리(721 ~ 900px 이름 2 ~ 4줄), 판결 파일철 탭(601 ~ 720px에서 고른 탭 하나가 철 폭을 다 차지).

## 검토한 대안
- 6막 읽기 지면 · 내 결과 지면 글자
  - 대안 A: 단 안의 글자 단위에만 하한. 지면 폭 · 두 단은 원래 `--u`, 제호 줄을 뺀 단(`.sheet > :not(.sheet-mast)`)은 `--u: max(--u, 7.6px)`. 내 결과 지면이 이미 쓰는 "글 요소만 `--u` 키우기"(× 1.12)와 같은 방식이다.
  - 대안 B: 721 ~ 1000px도 모바일처럼 한 단으로 쌓고 가운데 680px 폭에 둔다. 글자는 확실히 커지지만 태블릿에서 신문 두 단 모양이 없어지고 양옆이 빈다.
  - (제외) 지면 전체 `--u`에 하한: 지면 폭(118u)이 화면보다 넓어져 가로로 넘친다.
- 1면 머리기사: 900px 이하 한 단(모바일 쌓기 재사용) / 두 단 비율만 2 : 1 → 1.3 : 1.
- 16유형 갤러리: 721 ~ 900px 4열 세로 칸(그림 위, 넓은 화면 8열 칸과 같은 모양) / 2열 가로 칸(8행으로 길어짐).
- 판결 파일철 탭: 철 폭 기준 container query로 이름 표시 / 고른 탭 폭만 내용만큼 / 그대로(FE-151 예외).

## 선택한 방법과 이유 (사용자 결정: 네 항목 모두 추천안)
- 읽기 지면: 대안 A. 시험 주입으로 721 · 768 · 900px에서 가로 넘침이 없는 것을 먼저 확인했다. 본문 9.3 → 12px. 짧은 라벨(판결 주체 · 보조 줄 · 표 머리 · 광고 문구)은 모바일과 같은 `max(12px, …)`을 더했다. 약 930px(라벨은 약 1210px) 이상은 원래 값이 하한보다 커서 데스크톱(1440px)은 그대로다. 미디어 쿼리 구간을 따로 두지 않고 `max()`로 자연히 꺼지게 한 이유다.
- 1면 머리기사: 900px 이하 한 단. 모바일(≤ 720px)에서 검증된 쌓기 규칙을 그대로 써서 새 모양이 없다.
- 16유형 갤러리: 4열 세로 칸. 4행 그대로라 면 높이가 거의 그대로이고, 721px에서도 이름이 최대 2줄.
- 파일철 탭: 철 폭 기준. 이름 다섯 개가 들어가는 데 필요한 폭은 약 392px이라 기준을 철 420px로 잡았다(처음 600px로 잡았다가 재 보니 과했다). 390px 폰(철 약 350px)은 예전처럼 번호 탭, 화면 약 480px 이상은 이름이 다 보인다. 화면 폭이 아니라 철 폭이라 같은 철이 다른 틀에 들어가도 맞는다.

## 고려한 제약 사항
- 데스크톱(1440px) · 모바일(390px) 모양은 바뀌면 안 된다: 바꾼 규칙은 `≥ 721px` · `721 ~ 900px` · `max()` · 철 폭 container query로 범위를 묶었다. 901 · 1101 · 1440 · 720 · 390px에서 사건 목록 두 면을 develop과 비교해 같았다(901px 성향 테스트 면은 픽셀 해시만 달라 요소 299개의 자리 · 크기 · 글자를 비교했고 모두 같았다).
- 721px 읽기 지면에서 독자 의견 막대 줄의 긴 라벨 두 개("실형 5년 이상 ~ 10년 미만" 등)가 두 줄로 꺾인다. 카드 안 여백이 단위를 따라 조금 커진 탓이고 읽기에는 지장이 없어 두었다.
- 제호 줄 장식 글자(날짜 · "판결 체험 신문", 721px 약 6px)는 데스크톱에서도 10.9px인 장식이라 하한을 두지 않았다.

## 추후 재검토가 필요하면
- 실기기 태블릿(아이패드 사파리)에서 읽기 지면 두 단의 줄 길이와 1면 한 단 사진 크기를 확인한다.
