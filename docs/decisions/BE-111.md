# BE-111 의사결정 기록

## 문제 / 배경

- 실제 판례 조사로 서비스 후보 21건을 확정했다(상급심까지 확인, 1심 형 유지). 판례 조사의 선정 기준과 비식별화 프롬프트(`extract_system.md`)의 서비스 대상 조건(`eligibility`)이 서로 달랐다.
- 시험 사건 1건을 비식별화(extract)에 돌리자, 모델 세 개(gpt-6-luna · gpt-5.6-luna · gpt-5.6-terra) 모두 대상 아님으로 판정해 파이프라인이 멈췄다. 이유는 두 가지였다.
  - "최종 확정 판결이다": 1심 판결문만으로는 확정 여부를 알 수 없다.
  - "피고인이 범행을 자백했다": 판례 조사에서는 이 조건을 쓰지 않았다.
- 프롬프트와 스키마의 범죄 유형이 살인 · 사기 · 상해(`MURDER` · `FRAUD` · `INJURY`)뿐이라, 후보에 있는 강도상해 · 강도치상 · 특수절도 사건을 고를 값이 없었다.

## 검토한 대안

### 1. 확정 여부
- A. 프롬프트에 "확정 판결"을 그대로 둔다: 1심 판결문만 넣는 사건은 계속 대상 아님이 된다.
- B(선택). 모델은 "확정되지 않았다는 사정(상소 진행 중 · 파기 환송 등)이 판결문에 드러나지 않는다"만 본다. 확정 여부는 팀이 상급심 기록으로 따로 확인한다(판례 조사 단계에서 이미 확인).

### 2. 자백 조건
- A. 유지: 후보 21건 중 피고인이 다툰 사건이 빠진다.
- B(선택). 삭제: 팀 결정(2026-10-26).

### 3. 범죄 유형
- A안. 기존 세 유형에 억지로 넣는다(강도 → 재산범죄인 `FRAUD` 등): 형량 구간과 양형기준 분류가 맞지 않는다.
- B안(선택). `ROBBERY`(강도) · `THEFT`(절도)를 추가한다: 팀 결정(2026-10-27, enum 확정 D).
  - 화면 분류명은 둘 다 "재산범죄"다(형법 제38장 "절도와 강도의 죄").
  - 사전 판단 형량 구간
    - 강도는 법정형에 벌금이 없고(형법 제333조), 강도상해 · 치상은 무기징역이 있다(제337조). 그래서 벌금형을 빼고 무기징역을 더한 7개다.
    - 절도는 벌금형이 있어(제329조) 공통 7개를 쓴다.

## 선택한 방법과 이유

- 죄명 → 범죄 유형 대응을 프롬프트에 명시했다. 특별법으로 가중처벌된 경우도 기본 죄명으로 고른다.
  - `MURDER`: 살인 · 존속살해
  - `FRAUD`: 사기
  - `INJURY`: 상해 · 특수상해 · 상해치사 · 폭행치사
  - `ROBBERY`: 강도 · 강도상해 · 강도치상
  - `THEFT`: 절도 · 특수절도
- 위험운전치사상은 대상에서 뺐다(B안 논의에서 제외). 맞는 범죄 유형이 없어 프롬프트 조건에 남겨 두면 모델이 고를 값이 없다.
- 경합범은 형법 제37조 전단 · 후단을 모두 대상에서 뺀다고 조건에 명시했다(판례 조사 중 후단 사건이 걸러지지 않은 일이 있었다).
- `schema.py` `CRIME_TYPES`, API 명세(API 1 · 4, A-14), `docs/cases/README.md` 선정 조건을 같은 값으로 맞췄다.

## 고려한 제약 사항

- DB의 범죄 유형 CHECK(V1 · V2 · V11 · V24)와 형량 구간 데이터는 D(V31)가 넓힌다. V31이 운영에 반영되기 전에는 강도 · 절도 사건을 등록(load)하지 않는다.
- 자동 배포는 실패하면 이전 앱으로 되돌아간다. 이전 앱의 enum은 새 값을 모르므로, 강도 · 절도 데이터는 V31 배포가 안정된 뒤에 넣는다.
- `common.GUIDELINE_CATEGORIES`는 살인만 그대로 둔다. 양형기준 데이터가 살인범죄만 적재돼 있다. 살인이 아닌 사건은 지금도 양형기준 버전이 NULL이고, RAG는 경고를 남기고 양형기준을 찾지 않는다.
- RAG 유사 판례도 살인만 있어 `rag_store` · `rag_check`는 바꾸지 않았다.

## 추후 재검토가 필요하면

- 강도 · 절도 · 사기 · 상해의 양형기준을 적재하면 `GUIDELINE_CATEGORIES`에 분류를 추가한다.
- 상급심 기록이 없는 "확정 추정" 사건을 쓸지는 팀 결정 대기다.
