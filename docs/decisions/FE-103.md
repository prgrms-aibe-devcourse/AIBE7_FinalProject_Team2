# FE-103 의사결정 기록

10/26 critique 전 화면에서 수정 PR(FE-93 · 95 · 97 · 98 · 99 · 100 · 102)에 넣지 않은 P3 · 사소한 관찰 모음. 두 영역으로 나눠 PR을 따로 올린다.

## 1차 (영역 A: 화면 외곽 — 공통 헤더 · 메인 · 마이페이지 · 내 결과 · 커뮤니티 · 성향 테스트)

### 문제 / 배경
- 항목이 70개 가까이이고 대부분 작아서, 하나씩 고치기 전에 현재 코드로 재현되는지 먼저 재야 했다. 앞선 수정으로 이미 풀린 것도 있었다.

### 검토한 대안
- 모바일 Tab 순서: (A) 시각 순서를 DOM에 맞춰 로그인을 메뉴 아래로 내리기 (B) `tabindex` 양수 (C) 화면 폭에 따라 DOM 자리를 옮기기. A는 로그인이 눈에 안 띄게 되고, B는 쓰지 않는다. C를 택했다.
- 내 결과 그래프 키보드: (A) 점마다 `tabindex=0` (B) 그래프당 한 자리 + 방향키(roving). A는 한 화면에 Tab 정지점이 50개 안팎이 된다. B를 택했다. `role="img"`는 자식을 숨기므로 `group`으로 바꿨다.
- `/me` 진입 CLS: (A) 로딩 자리에 골격(skeleton) 그리기 (B) 컨테이너 `min-height`로 높이만 맞추기. 골격은 과하다. B로 CLS 0.424 → 0을 실측으로 확인했다.
- 끝난 일(첫 성향 테스트 · 재심) 표시: (A) 비활성 버튼 유지 (B) 상태 글. 누를 수 없는 것이 버튼처럼 보이는 것이 문제라 B를 택했다. 아직 조건이 안 맞아 못 누르는 "재심 청구하기"는 비활성 버튼으로 둔다.
- 커뮤니티 2단 기사 양쪽 맞춤: 좁은 폭에서 단어 사이가 벌어져 왼쪽 맞춤 + `text-wrap: pretty`로 바꿨다.

### 선택한 방법과 이유
- 위 대안 중 택한 것. 이유는 각 항목에 적었다.
- 공유 화면 유형 이름 중복: 뒤 카드(`.is-back`)의 밈이 앞 카드와 같은 글이라 삐죽 나온 자리에 잘려 보이고 낭독기가 두 번 읽었다. 뒤 카드 밈을 `visibility: hidden`으로 숨겼다.

### 처리하지 않은 것과 사유
- **`?view=` 주소 보존**: 마이페이지 하위 화면은 `history.state`로 새로고침 · 뒤로 가기가 이미 보존된다. URL까지 남기려면 라우터를 바꿔야 하는데 개인 화면이라 공유 이득이 적다.
- **모바일 헤더 메뉴 가로 스크롤 단서 · "목 데이터" 스위치 노출**: `import.meta.env.DEV`로 막혀 있어 운영에서는 해당 없음. "연출"은 사용자 설정이라 유지.
- **비활성 컨트롤 `opacity .55`**: 비활성 컨트롤은 WCAG 대비 기준에서 면제.
- **메인 포스트잇 문구**: 사용자 결정으로 그대로 둔다.
- **로그인 후 "이어서 하기"**: 새 기능에 가까워 FE-113으로 분리(Low, 필요 여부부터 결정).
- **책상 아래 나무 띠 약 90px**: 1440×900 실측 결과 패드 위 · 아래 여백이 비슷해 이상하지 않다.
- **프로필카드 글자 하한 · "성향 테스트 전" 대비**: 1~3위 단상 15.1px 이상, 4위 이하 11px는 FE-93의 의도된 하한. 대비는 5.97:1.
- **목데이터 딱지 일괄 숨김 토글**: "숨기지 않고 목데이터로 표기" 방침과 충돌.
- **마이페이지 성향카드 3겹 합치기**: 세 구역이 서로 다른 질문(지금 · 변화량 · 흐름)에 답해 합치면 정보가 빠지거나 클릭이 늘고, 유지하기로 한 레벨 · 시상대 결정과 부딪칠 수 있다. 사용자 결정으로 하지 않는다.
- **내 결과 헤드라인**: FE-100에서 이미 `{판사}의 판결은 {형량}`으로 바꿨고 사건 제목은 deck에 있다. 변경 없음.
- **성향 테스트 종이 페이지 모양(쿠폰 같은 모양 · 외톨이 단)**: 시안 판단이 필요한 시각 문제라 이번에는 건드리지 않았다.

### 고려한 제약 사항
- 헤드리스 크롬은 터치 · Safari 전용 동작을 재현하지 못한다. 모바일 헤더(로그인 위치 · Tab 순서)와 그래프 키보드 이동은 사파리 실기기 확인이 필요하다.
- 카드 설명 글자 대비(그라디언트 위)는 자동 측정이 안 돼 확인하지 못했다.

### 추후 재검토가 필요하면
- 시연 전에 성향카드 화면과 성향 테스트 종이 페이지를 직접 보고 어색하면 별도 이슈로 다룬다.
