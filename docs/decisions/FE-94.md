# FE-94 의사결정 기록

> 근거: [`FE-93.md`](FE-93.md) 후속 질문(3열 포럼 틀 · SNS형 피드가 메인의 집무실 은유와 따로 논다) · DESIGN.md "서명"

## 문제 / 배경
- 커뮤니티 글 목록 · 상세가 "좋아요 달린 SNS 피드 + 3열 포럼 틀"이라 메인의 집무실 은유와 따로 놀았다. 커뮤니티는 메인 책상 위 **노트북 속 화면**이라 책상 위 물건을 그대로 그리는 것은 세계관과 어긋난다.
- 처음 범위(목록 · 상세 구조 재설계)를 시안으로 비교하다 범위가 바뀌었다: **목록 · 상세는 그대로 두고, 글을 쓰는 순간과 서명이 남는 순간만** 편지처럼 만든다.

## 검토한 대안
- **구조 재설계 3안(시안)**: A 편지 더미 · B 주석 달린 사건 파일 · C 한 화면 결재함. 훑기 속도 · 구현 부담 · 은유 세기가 서로 엇갈렸다.
- **편지 은유 전면 적용(말투 + 받는 사람 줄 + 우표 딱지 + 서명 + 답장 선)**: 3열 틀은 두고 말투와 표시만 바꿔 로컬에서 확인했으나 **비직관적이라 취소하고 롤백했다**("글이 왜 편지인지", "받는 사람이 누구인지"가 말투만으로는 전해지지 않았다).
- **서명 만드는 방법**: ① 닉네임을 손글씨 글꼴로 씀(글자가 읽혀 서명 같지 않음) ② 순수 해시로 낙서 생성(닉네임과 무관해 보임) ③ **닉네임 글자 구조(한글 자모)가 획 모양을 정하고 해시는 변주만**(채택) ④ 직접 그리기(서버 저장 필요, FE-108로 분리).
- **쓰는 연출 구현**: ⓐ `stroke-dasharray` + `pathLength`(첫 시도) ⓑ 대시 + `getTotalLength` ⓒ **좌표를 앞에서부터 길이 순서로 이어 그림**(채택). ⓐ ⓑ는 사파리에서 긴 서명이 여러 토막으로 나뉘어 동시에 그려졌다.

## 선택한 방법과 이유
- **글쓰기 칸 편지화 + 닉네임 서명 생성**. 입력 항목 · 기능은 그대로 두고 받는 사람 줄 · 가장자리 장식 · 줄 쳐진 내용칸 · 서명란만 더한다. "서명하고 올리기"를 누르면 서명이 쓰인 뒤 글이 올라가고, 올리지 못하면 서명을 지운다. 글 상세 본문 끝에 글쓴이 서명, 3막 서명란에도 같은 부품을 쓴다.
- 서명은 닉네임의 글자 구조를 따라가되 읽히지 않는다(닉네임이 길면 서명도 길다). 서버 저장이 필요 없어 마감(11/04) 안에 프론트만으로 끝난다.
- **쓰는 연출은 한 획으로 처음부터 끝까지 0.8 ~ 1.2초**(서명 길이에 비례)로 정했다. 중간에 끊기거나 여러 획이 동시에 써지지 않아야 한다는 요구라서, 브라우저마다 다르게 도는 대시 기법을 버리고 좌표를 이어 그린다. 속도는 선 길이에 대해 일정하다.
- **로그인할 때 한 번 계산**한다(`saveUser`). 남의 서명은 처음 볼 때 만들어 닉네임별로 메모리에 둔다. 계산이 수 ms라 저장소에 따로 저장하지 않았다.
- **인장은 만들지 않는다.** 커뮤니티에 이미 있는 인장 시스템을 쓴다(처음에 서명 옆 도장으로 잘못 이해해 시안에 넣었다가 뺐다).

## 고려한 제약 사항
- 커뮤니티는 노트북 속 화면이라 현실 물건 은유를 그대로 쓰지 않는다. 목록 · 상세의 말투(글 · 댓글)는 이해하기 쉬운 쪽을 지킨다.
- 서명은 닉네임에 묶이므로 닉네임을 바꾸면 서명도 바뀐다(계정 고유 서명이 아니다).
- 서명이 읽히지 않아도 화면에는 닉네임이 함께 보인다. 비슷한 닉네임끼리 서명이 닮을 수 있다.
- 3막은 로그인 없이도 체험하므로 브라우저에 저장한 임시 식별값을 씨앗으로 쓴다.
- 사파리는 긴 선의 대시가 조각난다(위 구현 대안).

## 추후 재검토가 필요하면
- **직접 그린 서명 저장**(그리기 · 서버 저장 · 자동 서명과 전환)은 FE-108(후속).
- **안 읽은 편지 표시**(목록 왼쪽 점)는 서버가 읽음 여부를 줘야 해서 하지 않았다.
- 목록 · 상세를 집무실 은유로 바꾸는 일 자체(FE-94 처음 질문)는 열려 있다. 다시 할 때는 말투가 아니라 한눈에 읽히는 구조(예: 사건 단위 묶음)를 먼저 검토한다.
- 모바일 필터 접기 · 터치 44px 정리(FE-93에서 미룸)는 `adapt`로 따로 한다.
