# BE-37 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #80 본문.

## 문제 / 배경
- 사전 학습 점검(REQ-102)이 형량이 짧은 사건에서 변별력이 없었다. 징역 "가깝다" 기준이 ±2개월 고정이라 흔한 형량만 말해도 대부분 SUSPECT가 됐다.
- 가장 나쁜 1건이 최종 판정이라 우연히 한 번 맞혀도 CONTAMINATED가 됐고, 무료 한도로 10회 중 일부만 응답해도 판정을 확정했다.

## 선택한 방법과 이유
- 응답 하나를 `KNOWS · EXACT · CLOSE · SAME_TYPE · INVALID · FAR`로 분류하고, 회차 묶음은 **비율**로 판정한다.
- 징역 허용 오차는 실제 형량의 15%, 단 1 ~ 6개월로 제한(긴 형량에서 느슨해지지 않게). 벌금은 10% 유지.
- 응답 수가 `minAnswered`(기본 5) 미만이면 새 판정 `INSUFFICIENT`로 두고 확정하지 않는다. 파이프라인에서 `stop`(기본) · `continue` · `exclude`를 고른다.
- 판정 근거에는 예측 형량 값을 쓰지 않는다(생성 기록으로 이어지므로).
- 저장해 둔 실제 응답을 새 기준으로 재판정해 보니, 짧은 형량 사건의 SUSPECT가 `CLEAN`으로, 2/10만 돌아온 모델은 `INSUFFICIENT`로 바뀌었다.

## 고려한 제약 사항
- 기준값(15% · 50% · `minAnswered`)은 `stages.contamination.criteria`로 사건 · 팀 판단에 맞게 조정할 수 있다.
- 점검 프롬프트는 바꾸지 않았다(`CONTAMINATION_PROMPT_VERSION` 유지).
