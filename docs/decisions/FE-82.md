# FE-82 의사결정 기록

## 문제 / 배경
- 성향카드 화면에도 프로필카드처럼 테두리 · 배경 · 책갈피를 꾸미는 기능이 필요했다.
- 프로필 꾸미기 저장(P-7)은 서버가 값 목록을 검사하고, 필드가 빠지면 400을 돌려준다.

## 검토한 대안
- 대안 A: 프로필 꾸미기(`profileDeco`)에 성향카드 필드를 더해 P-7로 함께 저장한다. 서버에 저장되지만 BE 변경이 먼저 필요하고, 이번 이슈는 FE만 다룬다.
- 대안 B: 성향카드 꾸미기를 별도 값으로 두고 이 브라우저(localStorage)에 저장한다. BE 없이 끝나고 "카드 아래 성향"(FE-77)이 이미 같은 방식이다. 브라우저를 바꾸면 값이 사라진다.

## 선택한 방법과 이유
- 대안 B. 저장은 `utils/typeCardDeco.js`가 맡고, 서버로 옮길 때 이 파일만 바꾸면 된다.
- 값 목록(테두리 · 배경 · 책갈피)과 해금(도전과제)은 프로필카드와 같은 것을 쓴다. 고르기 칸은 `myPage.js`의 견본 · 책갈피 묶음을 대상(`PROFILE_TARGET` · `TYPE_TARGET`)만 바꿔 같이 쓴다.
- 성향카드 배경에는 "기본"(원래 타로카드 모양)을 더하고 기본 값으로 둔다. 기존 카드 모양이 바뀌지 않고, 이미 쓰는 사람에게 갑자기 밝은 카드가 나오지 않는다.
- 꾸밈은 성향카드 화면의 지금 유형 카드와 첫 화면 성향카드에만 입힌다. 사건별 성향카드(내 결과)와 "처음 → 다시 정함 → 지금" 줄의 카드는 입히지 않는다.

## 고려한 제약 사항
- 성향카드는 어두운 바탕에 밝은 글자라서, 밝은 배경을 고르면 글자 · 선 색을 따로 처리해야 한다.
- 윗변 별 장식(`::after`)은 윗변 장식 선택(별 · 달 · 숫자)을 검토하다가 "기본에서도 없는 것으로" 하기로 해서, 꾸미기 여부와 상관없이 모든 성향카드(내 결과 지면 포함)에서 뺐다. 밝은 배경에서 별만 따로 숨기는 안은 쓰지 않았다.

## 추후 재검토가 필요하면
- 서버에 저장하려면 P-7에 필드를 더하거나 성향카드 꾸미기 API를 새로 만든다. 브라우저를 바꿔도 유지되게 하려면 BE 작업이 필요하다.
