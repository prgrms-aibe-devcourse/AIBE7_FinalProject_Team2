## 문제 / 배경

- 초기에는 1막부터 다시 보기의 엽서를 복원하기 위해 API 3에 본인 사전 판단 구간을 추가하는 안을 검토했다.
- PR #198 리뷰에서 이 안이 “두 판단을 서로 영향 없이 따로 내리도록 사전 판단은 최종 비교에서 처음 공개한다”는 핵심 기획과 충돌함을 확인했다.
- 2026-10-20 팀 논의에서 진행 중 사전 판단 재확인 금지, 1막부터 다시 보기 삭제, 완료 후 결과 화면의 독자 의견에서 최초 사전 판단 공개, 재판부 비교 방향의 서버 계산을 확정했다.

## 검토한 대안

- API 3 조기 공개 유지 또는 특정 진행 상태부터 허용: 진행 중 재확인 금지 원칙과 맞지 않아 제외했다.
- PRE 누락 시 API 3에 null을 반환: 사전 판단 필드 자체를 추가하지 않으므로 별도 처리가 필요하지 않다.
- 프론트 label 파싱 유지: 표시 문구 변경에 취약하고 서버의 형벌 종류·개월 범위 비교 규칙과 중복되므로 제외했다.

## 선택한 방법과 이유

- API 3 조기 조회 초안을 제외하고 API 2·3 공용 `ExperienceResponse`의 기존 5개 상태 필드를 유지한다. 소유권 검증과 읽기 전용 상태 조회를 그대로 사용한다.
- API 3은 상태에 관계없이 사전 판단·AI·재판부 판결·비교 결과를 반환하지 않는다. PRE를 조회하지 않으므로 PRE 기록 누락이 상태 조회까지 막지 않는다. API 14의 데이터 불일치 정책은 유지한다.
- 체험 완료 후 `COMPLETED`에서만 API 14를 조회할 수 있다. 기존 `preToFinal.preJudgment.label`로 결과 화면의 독자 의견에 처음 선택한 형량을 표시한다.
- API 14에 `preToCourt.direction`을 추가한다. 이미 조회한 PRE와 COURT에 `PreToFinalDirection.of()`를 적용하므로 추가 판결 조회나 새 계산 규칙이 없다.
- **재판부가 더 무거우면 HEAVIER**, 더 가벼우면 LIGHTER다. SAME은 동일 형벌 종류 및 사전 판단 구간에 속한다는 뜻이며 정확한 형량 일치를 의미하지 않는다. 사용자 기준 문구는 HEAVIER → “실제 사건보다 가볍게 판단”, LIGHTER → “실제 사건보다 무겁게 판단”으로 대응한다.
- 공개 시점·상태 전이·판단 수정 금지·성향 산식·DB 스키마는 유지한다. 최종 계약은 [API 명세](../api-specification.md) API 2·3·14를 따른다. develop에 포함되지 않은 API 3 초안은 별도 릴리스 이력으로 남기지 않고 BE-77 이력을 v0.35로 통합한다.

## 검증 결과

- PR #198은 API 3 확장을 제외하고 API 14 비교 기능을 유지한 상태로 최종 승인·머지됐다.
- 최종 구현 검증: 관련 5개 클래스 85건, 전체 60개 클래스 630건 통과(2026-10-20). BE-87 전용 PostgreSQL·Redis와 보호 설정을 사용했다.
- API 2·3의 모든 상태에서 기존 5개 필드·판단 비노출·상태 불변, PRE 누락 시 상태 조회 정상 응답을 검증했다. API 14의 방향·경계·집행유예·감경·label 독립성과 완료 전 차단도 검증했다.
- 이 문서 정리에서는 테스트를 재실행하지 않았다.

### 연동 확인 대상

- `comparisonStage.js`의 편집부 의견과 `{editor}` 대사를 서버 direction 기반으로 전환한다. `preJudgmentCompare.js`의 label 파서는 문구 변환 함수로 대체할 수 있다. 필드 누락·잘못된 direction은 비교 문구만 생략하고 SAME으로 간주하지 않는다.
- Mock API 14에 `preToCourt.direction`을 추가하고 숫자 구간 비교 및 방향·누락 값 테스트를 맞춘다. 정상 Real 응답에는 새 전송 함수가 필요하지 않다.
- UI 완료본의 반영 위치와 캐시 경로 제거 여부를 먼저 대조한다. API 3에 사전 판단을 추가하는 연동은 하지 않는다.
- 관련 기존 이슈는 [FE-31](https://aibe7-team2-final.atlassian.net/browse/FE-31)(7·8막), [FE-55](https://aibe7-team2-final.atlassian.net/browse/FE-55)(독자 의견·리뷰 엽서), [FE-47](https://aibe7-team2-final.atlassian.net/browse/FE-47)(커뮤니티)이다. 조회한 본문에는 `preToCourt` 전환이 명시돼 있지 않다. 담당자와 기존 이슈의 추적 범위를 확인해 중복 작업을 피한다.
