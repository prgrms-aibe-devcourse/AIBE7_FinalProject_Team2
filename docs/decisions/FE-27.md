# FE-27 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #138 본문. 이후 막은 FE-28 ~ FE-32가 이 무대 위에 쌓인다.

## 문제 / 배경
- 판결 체험을 게임식 8막(REQ-089)으로 바꾸면서, 막마다 따로 만들지 않고 쓸 공통 무대와 대본 구조가 필요했다.

## 선택한 방법과 이유
- 공통 무대 부품(`components/stage.js` · `stage.css`)에 막 칩 · 장면 · 캐릭터 · 역할 이름표 · 대사창 · 키보드 진행을 모았다. 판단에 필요한 내용은 화면이 넘기는 **카드**로 띄운다.
- 대사는 사건별 `content/case-1/script.json`에 둔다. 대본이 있는 사건만 무대로 진행하고, 대본이 없는 사건은 기존 MVP 화면을 그대로 쓴다.
- 서버 연동(제출 · API · 수정 불가 규칙)은 건드리지 않고 화면 연출만 입힌다.
- 접근성: 타이핑 글자는 숨기고 `aria-live`가 문장을 한 번 읽게 한다. `prefers-reduced-motion`이면 즉시 표시한다. 색은 기존 역할 토큰만 쓴다.

## 고려한 제약 사항
- 캐릭터 컷은 원본 이미지 레포의 PNG를 GitHub raw로 직접 읽는다(`shortcut:` 주석). 웹 webp 변환(WBS 7.6.8) 때 `public`으로 옮긴다.
- 3막 이후 · 신문 연출 · 사건 디테일(S-20)은 다음 이슈로 나눴다.
