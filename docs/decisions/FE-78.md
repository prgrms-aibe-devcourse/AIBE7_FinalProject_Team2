# FE-78 의사결정 기록

## 문제 / 배경
- 성향 테스트 화면(문항 · 결과 · 풀이 · 공유)을 [`DESIGN.md`](../../DESIGN.md) 기준으로 다듬는다.
- 로컬에서 브라우저 확장이 연결되지 않아 화면은 코드 기준으로 점검했고, 눈으로 보는 확인은 PR 리뷰 단계로 남긴다.

## 검토한 대안
- **종이 계열 흰색 4종(카드 `#fff` · 페이지 `#fdfcfa` · 부드러운 종이 `#f7f3ee` · 책상 종이 `#f6f3ec`)**
  - 대안 A: 4종을 모두 한 값으로 통일 — 카드 · 페이지 · 옅은 면의 계층이 사라지고, 흰색 → 옅은 면으로 바뀌는 보조 버튼 호버가 전 화면에서 보이지 않게 된다.
  - 대안 B: 구분이 안 되는 한 쌍(책상 종이 ↔ 부드러운 종이)만 합침 — 영향이 작고 안전하다.
- **종이 위 보조 버튼 호버**
  - 대안 A: 전역 `--color-surface`를 더 진하게 — 모든 화면 배경에 영향.
  - 대안 B: 성향 테스트(`.personality-page`)에서만 kraft 16% 틴트 + 진한 테두리로 덮어쓰기 — 범위가 작다.
- **검사지 ↔ 결과지 철 돌리기를 공유 화면 → 검사지에도 쓰기**
  - 대안 A: 반대 방향 키프레임을 새로 만든다.
  - 대안 B: 기존 `folder-turn`(결과지 연출)과 `markFolderTurn` / `setFolderTurnFrom`을 그대로 재사용 — 눕힌 철 ↔ 세운 철이 같은 변환이라 시작 크기 계산식이 그대로 맞는다.
- **공유 화면의 내로 · 남불 그림 두 장**
  - 대안 A: 큰 카드 아래 작은 카드 — 처음 만들었다가 "겹쳐 놓인 사진" 의도와 달라 버렸다.
  - 대안 B: 같은 크기 카드 두 장을 겹치고 어느 쪽을 눌러도 앞뒤가 바뀜(CSS 전환, 투명 버튼은 낭독 · 키보드용).
- **인덱스 탭 모양**: 둥근 사각형 두 개 → 윗변이 좁은 사다리꼴(`perspective` 변형)로 겹쳐 꽂기. 글자는 변형 밖에 둬서 일그러지지 않는다.

## 선택한 방법과 이유
- 흰색 4종은 **대안 B(한 쌍만 합침)**: `--palette-sheet`가 `--palette-paper-50`을 가리키게 했다. 카드 · 페이지 · 면 계층은 의도된 구분이라 남기고, 합칠지 여부는 DESIGN.md "현재 코드와 차이" 19번에 결정 대기로 둔다.
- 종이 위 보조 버튼 호버는 **대안 B(성향 테스트에만)**. 다른 종이 위 화면은 20번에 남겼다.
- 철 돌리기는 **재사용**. 값은 `sessionStorage`로 한 번만 넘기고, 떠나던 철의 **스크롤 위치도 함께 저장**해 새 화면이 맨 위에서 시작해도 눈에 보이던 자리에서 도는 것처럼 이어지게 했다. **모바일(≤ 720px) · 연출 끄기 · 동작 줄이기에서는 건너뛴다**(`canTurnFolder`).
- 풀이 탭은 결과 탭과 **다른 캐릭터**(이미지 번호 ±16)를 보여 준다. 유형 이미지가 내로 01 ~ 16 · 남불 17 ~ 32 번호표라 서버 변경 없이 구할 수 있다.
- 4축 막대 색은 마이페이지와 같은 값을 **`--color-axis-*` 토큰**으로 만들어 쓴다(마이페이지의 직접 값 정리는 이번 범위 밖).
- `--color-primary`(옛 이름)는 값이 `--color-accent`와 같고 마이페이지에서 쓰이지 않아 전부 치환하고 별칭을 지웠다.
- 풀이 문구(일상에서는 · 판결을 볼 때는) 16유형 32문단은 `~요`체로 통일했다. 원문 문서(`docs/personality-test-content.md`)를 먼저 고치고 SQL과 목 데이터를 맞췄다.

## 고려한 제약 사항
- `R__personality_content.sql`은 반복 마이그레이션이라 문구를 바꾸면 다음 기동 때 운영 DB 문구도 갱신된다. `share_id` · 이미지 번호는 건드리지 않아 공유 링크는 유지된다.
- DESIGN.md의 P3(선택지 호버)가 "미확정"이라, 문서 표 그대로(`테두리 heading + kraft 16%`)만 적용했다.
- 판결 체험의 종이 귀(`.folder-curl`) · 책갈피(`.folder-bookmark`)는 `.verdict-page`에 묶여 있어 성향 결과지용을 따로 만들었다.

## 추후 재검토가 필요하면
- 종이 귀 · 책갈피를 판결 체험과 공용 컴포넌트로 통일(DESIGN.md 차이표 21번 · P7 표).
- 흰색 계층(카드 · 페이지 · 면)을 합칠지, 다른 종이 위 보조 버튼 호버를 확대할지.
- 마이페이지의 `--axis-*` 직접 값을 새 `--color-axis-*` 토큰으로 바꾸기.
