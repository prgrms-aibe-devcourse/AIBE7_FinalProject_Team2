# FE-31 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #151 본문.

## 문제 / 배경
- 6 · 7 · 8막은 한 무대에서 이어지는데, 기획서의 화면(S-07 · S-08 · S-09)은 각자 주소가 있다. 연출 흐름과 주소 · 서버 상태를 어떻게 맞출지 정해야 했다.

## 선택한 방법과 이유
- 무대는 이어 받고 **주소만 바꾼다**(`/result/ai` → `/result/court` → `/result/compare`). 라우터에 `navigate(..., { keepView })`를 추가하고 `replaceState`로 방문 기록이 늘지 않게 했다.
- 8막은 판사의 책상 위 "다음 날 신문"으로 만들고, 카메라가 기사마다 비슷한 크기로 옮겨 간다(`components/sheetCamera.js`, 줌인 또는 줌아웃 한쪽만).
- 백엔드는 바꾸지 않는다. 주소 · 상태값 · API 11 ~ 14 계약은 API 명세 1-6 "보낼 화면" 표 그대로다.

## 고려한 제약 사항
- `replaceState` 때문에 7 · 8막에서 뒤로 가기를 누르면 S-07 · S-08을 건너뛰고 판결 입력(S-06) 기록으로 갔다가 서버 상태에 맞는 화면으로 다시 보내진다. 판단을 되돌릴 수 없는 흐름이라 의도한 동작이다.
- 세계관 문서의 "실제 판결(S-08)에는 정령이 나오지 않는다"와 다르다. 지금 단계에서는 남불이 판사로 읽는 것으로 정했다.
- 공유 링크는 임시로 사건 목록(`/cases`)이며(`shortcut:` 표시), S-20(FE-32)이 머지되면 사건 상세로 바꾼다.

## 추후 재검토가 필요하면
- 1막 확정, 역할별 자리 · 이름표 위치, 3막 절차 이름 "법률 안내" 변경 여부는 보류 상태였다.
