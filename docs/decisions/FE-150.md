# FE-150 의사결정 기록

## 문제 / 배경
- 메인 책상 소품 · 집무실 바닥 · 법정 · 도장 · 배경이 CSS 그라디언트와 인라인 SVG로 그려져 있어 질감이 부족했다. 이를 이미지로 바꿔 완성도를 올리되 **지금의 형태 · 배치 · 색 약속은 유지**해야 했다.
- 이미지는 생성형 도구로 소품마다 따로 뽑는다. 캔버스 크기와 가장자리 품질이 소품마다 다르고, 일부는 CSS 효과(신문 말림 · 러그 접힘)와 맞물려 있다.

## 검토한 대안
- 스타일 A+(캐릭터와 같은 평면 언어, 완성도만 올림): 캐릭터와 가장 잘 맞고 가볍다. 체감 상승이 작을 수 있다.
- 스타일 B-(A+에 약한 재질 한 겹): 형태는 그대로, 나뭇결 · 펠트 · 종이 섬유가 생긴다. 소품이 캐릭터보다 사실적으로 보일 위험이 있다.
- 스타일 C(잉크 + 구아슈): 신문 · 법정에 어울리지만 소품 8종 일관성 유지가 어렵다.
- 질감 처리: (a) 이음매 없는 타일로 반복, (b) 한 장을 `cover`로 덮기, (c) 거울로 이어 타일.

## 선택한 방법과 이유
- **B-** 로 확정(사용자 결정). 생성 프롬프트는 전부 같은 스타일 문장 · 색 토큰 값을 넣어 따로 뽑아도 한 벌이 되게 했다.
- **서류철은 코드 원본 방향**(앞표지 왼쪽)으로 뽑고 `scaleX(-1)`을 지웠다(사용자 결정).
- **질감은 기본 (b)**: 패드 · 러그 · 법정처럼 크기가 화면마다 변하는 것은 완성된 모양이 아니라 질감 한 장을 덮고 모양은 CSS가 맡는다. AI 생성 질감은 가장자리가 이어지지 않아(이음매 차이가 인접 열의 2 ~ 4배) 타일을 쓰면 줄이 보인다.
- **마루만 (c)**: 반복이 필요해 위아래를 거울로 이은 타일을 만들어 이음줄을 없앴다.
- **러그는 러그색 막(80%)을 덮어 대비를 낮췄다.** 원본 직물이 데님처럼 거칠어 집무실 톤(차분 · 묵직)과 맞지 않았다.
- **CSS 효과는 유지**: 신문 말림은 `clip-path`와 CSS 종이색으로 그리므로 이미지는 네 모서리 밝기가 균일한 종이 한 장이어야 한다(그렇게 뽑았다). 러그 접힘 · 안내 종이 귀퉁이도 같다.
- **잉크 도장은 되돌려 평평하게(12.8도) 써서 CSS `rotate`로 다시 기울인다**(이미지에 기울기를 구우면 글자와 어긋난다). 빨간 인주는 쓰지 않고 네이비 잉크로 했다.
- **카드 꾸미기는 새 선택지를 더했다(사용자 결정)**: 카드 배경 14종과 이미지 테두리 4종을 `FRAMES` · `BACKGROUNDS`에 더하고, 목 서버 해금표에서 기존 도전과제(첫 판결 · 내 성향 카드 · 단골 손님 · 수집가 · 일주일 출석 · 세 번째 판결 · 열혈 수집가 · 한 달 출석)에 나눠 배정했다. `cases-5` · `collect-50`은 BE-146 결정(경험치만)을 지켜 건드리지 않았다. 테두리는 기존 CSS 4종(원목 · 금박 · 법정 네이비 · 바느질)을 대체하지 않고 별개 선택지(참나무 · 황동 · 법정 · 실 바느질 액자)로 두었다. 이미지 테두리는 정사각 그림을 `border-image`로 9등분해 늘인다.
- 형식: 투명 소품은 webp(알파 유지), 앱 아이콘은 png(apple-touch-icon이 webp를 못 읽음).
- 원본 PNG(수십 MB)는 저장소에 두지 않고 로컬에만 둔다. 저장소에는 후처리한 webp만 올린다(`public/images/` 아래 약 1.6MB).

## 고려한 제약 사항
- 메인 첫 화면 소품 8종 합계 약 380KB(목표 1MB 안쪽).
- 날아오는 커피잔은 화면 짧은 변의 95%까지 커져 큰 해상도(700 → 1402px 원본)를 따로 쓴다.
- 1막 · 6막 화면은 흐름 순서 가드 때문에 직접 접근이 안 돼 이번에 눈으로 확인하지 못했다. 사파리도 아직 확인하지 않았다.

## 추후 재검토가 필요하면
- 6막 법정 사진은 흑백 필터가 걸리는데 바닥과 책상의 명도가 비슷해 구분이 약할 수 있다.
- 앱 아이콘 · 탭 아이콘은 스탠드 시안이다. 로고가 확정되면 바꾼다. OG 이미지는 글자를 올릴 배경만 있고 연결하지 않았다.
- **실제 서버 카탈로그(`backend/.../profile/domain/ProfileDecoCatalog.java`)에 새 id(배경 14 · 테두리 4)와 도전과제별 보상을 같은 표로 더해야 한다**(후속 BE 이슈). 그 전까지 실제 모드에서는 새 항목이 잠긴 채 보이거나 저장되지 않는다.
- 반복해서 쓰는 질감이 더 생기면 같은 거울 타일 방식으로 이음매를 먼저 없앤다.
