# FE-164 의사결정 기록

## 문제 / 배경
- 6막 신문 지면에서 "판단 요소" 표가 길어지면 같은 행의 "세 판결, 나란히"가 비어 보이는 공백이 생겼다.
- 5막 피고인석(`stand`)에서 원본이 오른쪽을 보는 내로가 왼쪽에 선 검사 반대편을 보고 있었다.
- 성향테스트 11번 지면 문구가 현실감 없이 어색했다.
- 커뮤니티 작성글 삭제 버튼 요청 → 백엔드에 삭제 API가 없어 이 이슈에서 다루지 못했다.

## 검토한 대안
- 공백: (A) 지면을 좌 · 우 두 묶음으로 나눠 따로 쌓기 → 카메라 · 기사 포커스(`sheet-*` 직계 자식 기준)가 얽혀 위험이 크다. (B) 세 판결이 남는 높이를 같은 몫으로 나눠 갖기 → CSS 두 줄. 
- 피고인 방향: (A) `flipFor`의 가운데 규칙 자체를 바꾸기 → 슬롯 30(판사 · 카드 장면)까지 바뀐다. (B) 피고인석(`stand`)만 `placeFor`에서 따로 정하기.

## 선택한 방법과 이유
- 공백은 (B): 레이아웃 구조와 카메라 로직을 건드리지 않고 표 길이에 상관없이 채워진다.
- 방향은 (B): 요청 범위(피고인)에만 적용한다. 검사는 항상 왼쪽 자리라 피고인석은 왼쪽을 보게 고정했다. 기존에 "원본 방향"을 못 박던 테스트를 새 규칙으로 고쳤다.
- 11번 문구: 점수 방향(엄격 쪽 B)과 선택지 문구는 테스트가 고정하므로 상황 설명과 대사만 현실적인 분리배출 상황으로 바꿨다.

## 고려한 제약 사항
- 지면 문구는 문항 id로 서버 답과 이어져 선택지를 바꾸면 점수 뜻이 달라진다(`paperQuestions.test.js`).
- 삭제 버튼은 BE-167(삭제 API) 이후 별도 FE 작업으로 진행한다.

## 추후 재검토가 필요하면
- 참나무 액자가 카드 꾸미기 미리보기에서 안 보인다는 제보는 Chrome · Safari 재현 확인 결과 재현되지 않아 보류했다. 다시 제보되면 상태(선택 액자 · 로그인 · 해금)를 받아 확인한다.
