# FE-83 의사결정 기록

## 문제 / 배경
- 마이페이지 "환경 설정"이 "곧 열려요" 껍데기였다. 틀을 먼저 잡고 항목은 나중에 더하거나 빼기 쉽게 만든다.
- 알림 같은 항목은 서버 API가 없고, 소리 · 글자 크기는 앱 쪽에 아직 연결할 곳이 없다.

## 검토한 대안
- 대안 A: 실제로 동작하는 항목만 넣는다. 지금 동작하는 것은 화면 연출(motion) 하나뿐이라 화면이 비어 보인다.
- 대안 B: 항목을 넉넉히 넣고, 연결되지 않은 항목은 "곧 적용"으로 표시한 채 값만 이 브라우저에 저장한다.

## 선택한 방법과 이유
- 대안 B. 항목은 `utils/appSettings.js`의 표 하나(`SETTING_GROUPS`)로 정의하고 화면이 표를 그린다. 항목을 더하거나 빼는 일이 표 한 줄이고, 앱 쪽에서 연결할 때는 `getSettings()`를 읽고 `soon`만 떼면 된다.
- 화면 연출은 공통 헤더의 "연출" 스위치와 같은 값(`utils/motion.js`)을 쓴다. 같은 설정을 두 곳에 저장하면 어긋나기 때문이다.
- 서버 저장은 하지 않는다(알림 API 이후).

## 고려한 제약 사항
- 기기의 "동작 줄이기"가 켜져 있으면 연출 스위치를 바꿀 수 없다(motion.js 규칙을 따른다).

## 추후 재검토가 필요하면
- 알림 설정은 서버 저장으로 옮겨야 한다(기기를 바꿔도 유지). 소리 · 글자 크기는 연결 작업이 따로 필요하다.
