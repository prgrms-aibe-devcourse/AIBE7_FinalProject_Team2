# BE-85 의사결정 기록

## 문제 / 배경

COMMON-40(generate 모델 고정)은 여러 사건 × 여러 모델 × 다회차 테스트 결과를 근거로 모델 하나를 고른다. 그런데 `compare.py`는 사건 1개(`batch_dir` 1개) 단위로만 비교표를 만들어서, 여러 사건을 비교하려면 사람이 표 여러 개를 눈으로 합산해야 했다. 또 징역 형량은 최소·중앙값·최대만 있어 "같은 모델이 매번 비슷한 형량을 내는가"(안정성)를 숫자로 볼 수 없었다.

## 검토한 대안

### 1. 여러 사건을 어떻게 입력받을 것인가

- **대안 A — 새 서브커맨드(`compare.py aggregate <dir1> <dir2> ...`)를 만든다.** `generate.py`가 `run`/`import` 서브커맨드를 쓰는 것과 일관된다. 다만 기존 사용자가 외워 둔 `compare.py <batch_dir>` 형태와 완전히 달라져, 단일 사건 비교와 사건 간 집계가 서로 다른 명령처럼 느껴진다.
- **대안 B(선택) — 기존 위치 인자 `batch_dir`를 `nargs="+"`로 바꿔, 1개면 지금과 똑같이 동작하고 여러 개면 집계 모드로 전환한다.** 기존 호출(`compare.py out/runs/case ...`)은 글자 하나 안 바꿔도 그대로 동작해 하위 호환이 완전하다. "여러 사건을 보고 싶으면 폴더를 여러 개 나열한다"는 것도 직관적이다.

### 2. 판단 요소 관련 칸(요소 방향 일관성 · 전체 다수 의견 일치율)을 집계에도 넣을 것인가

- **대안 A — 사건마다 `factorId`가 다르니, 같은 번호끼리는 같은 의미라고 보고 그대로 합친다.** 틀린 가정이다. 사건마다 판단 요소 자체가 다르므로(예: 사건 1의 "3번 요소"와 사건 2의 "3번 요소"는 전혀 다른 사실관계) 숫자를 합치면 의미 없는 값이 나온다.
- **대안 B(선택) — 집계표에서는 요소 일관성 · 전체 다수 의견 칸 자체를 뺀다.** 사건별 비교표(`compare.py <사건 1개>`)에는 이미 있으니 필요하면 거기서 본다고 안내한다.

### 3. "사건 간 편차"를 어떤 지표로 볼 것인가

- **대안 A — 모든 사건의 형량을 그대로 풀어서(pool) 표준편차 하나만 본다.** 이미 있는 "징역 표준편차"(아래 4번)와 사실상 같은 값이 되어, 사건 자체의 난이도 차이(사건이 다르면 형량 자체가 다른 게 당연함)와 모델의 회차 간 변동(같은 사건에서 매번 다른 답을 내는 것)이 뒤섞인다.
- **대안 B(선택) — 사건별 중앙값을 먼저 구하고, 그 중앙값들의 표준편차("사건별 중앙값 편차")를 따로 낸다.** 회차 간 변동은 기존 "징역 표준편차 · IQR"이 보여주고, "사건이 바뀌어도 이 모델이 비슷한 수준으로 선고하는가"는 이 값이 따로 보여준다. 모델이 한 사건에만 등장하면(비교 대상이 없어) 계산하지 않는다(`None`).

## 선택한 방법과 이유

### 1. 위치 인자를 `nargs="+"`로 바꿔 1개/여러 개로 모드를 나눔 (대안 B)

`len(args.batch_dir) == 1`이면 기존 코드 경로(요소 일관성 · 법원 비교 · 사건 하나의 비교표)를 그대로 타고, 2개 이상이면 새 `aggregate()` 경로를 탄다. `--case` · `--court`는 사건마다 다른 값이라 여러 사건 합산과 함께 쓸 수 없게 `CompareError`로 막았다.

### 2. 요소 일관성 · 전체 다수 의견 칸은 집계표에서 뺌 (대안 B)

대신 집계표 머리말에 "사건별 비교표를 따로 보라"는 안내를 넣었다(`render_markdown_aggregate`).

### 3. 징역 최소·중앙값·최대에 표준편차·IQR을 추가 (완료 조건의 "형량 산포")

`statistics.pstdev`(모집단 표준편차)와 사분위수(`statistics.quantiles(..., method="inclusive")`)로 Q3-Q1을 계산한다. 값이 2개 미만이면 퍼진 정도를 말할 수 없어 `None`으로 둔다(기존 `consistency()`가 회차 2개 미만일 때 `None`을 주는 것과 같은 규칙). 이 칸은 **사건 1개짜리 비교표에도** 넣었다 — 한 사건 안에서도 "같은 모델이 회차마다 들쭉날쭉한지"는 의미 있는 정보이기 때문이다.

### 4. "사건별 중앙값 편차" 지표 추가 (대안 B)

사건마다 해당 모델의 징역 중앙값을 구한 뒤, 그 중앙값들의 모집단 표준편차를 낸다. 값이 작을수록 "이 모델은 사건 난이도가 달라져도 비슷한 수준으로 선고한다"는 뜻이다.

## 고려한 제약 사항

- **기존 단일 사건 비교표의 출력·CLI를 바꾸지 않음**: `compare.py <폴더 1개>`의 동작·칸 구성(새로 추가한 징역 표준편차·IQR 2칸 제외)은 그대로다. 기존 테스트(`test_compare_summary`)가 그대로 통과한다.
- **표준 라이브러리만 사용**: `statistics` 모듈만으로 계산한다(이 폴더의 "설치 없이 실행" 원칙).
- **권고 범위 판정은 사건마다 자신의 `recommended` 값을 쓴다**: 집계표의 "권고 범위 안" 칸은 사건마다 다른 권고 범위로 판정한 횟수를 단순 합산한 값이다. 사건 중 하나도 `recommended`가 없으면 그 모델 행은 `None`이다.

## 추후 재검토가 필요하면

- 지금은 "사건별 중앙값 편차" 하나만 추가했다. COMMON-40 진행 중에 다른 산포 지표(예: 사건별 IQR의 평균)가 더 필요해지면 그때 추가한다.
