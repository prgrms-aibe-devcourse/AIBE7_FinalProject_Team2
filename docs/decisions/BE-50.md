# BE-50 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #94 본문과 `docs/rag-precedent-sources.md`. 수집처별 세부와 건수는 그 문서를 보고, 여기에는 결정만 적는다.

## 문제 / 배경
- AI 판결 RAG에 쓸 판례를 어디서 어떻게 모을지 정해야 했다(약관 · 자동 수집 가능 여부 · 건수 · 중복).

## 검토한 대안
- 수집처 7곳을 약관 · robots.txt · API · 비용 기준으로 비교했다(상세는 `docs/rag-precedent-sources.md`).

## 선택한 방법과 이유
- law.go.kr Open API(자동 수집) + LBox Open(내려받기). 판결공보는 law.go.kr와 대부분 겹쳐 따로 수집하지 않는다. 유료 열람 · 출처가 불명확한 가공 데이터는 쓰지 않는다.
- 사람이 하나씩 확인하지 않고 후보를 전부 적재하되(BE-51), 품질은 샘플 사건 검색으로 확인한다.
- 1990년대 판례까지 포함하므로 양형기준 시행 전 · 법정형 개정 전후 · 사건 그룹을 표시 항목으로 둔다.

## 고려한 제약 사항
- 사건번호가 들어간 후보 목록 · 수집 스크립트는 비공개 저장소에 두고, 공개 문서에는 집계만 남긴다.
- 약관 인용 일부는 웹페이지 요약을 거쳐 원문 대조가 필요했고, LBox 라이선스 문의 등이 남아 있었다.

## 추후 재검토가 필요하면
- LBox의 사용 가능 여부는 이후 BE-51에서 "사용 보류로 적재"로 정리됐다. 최신 상태는 `docs/rag-precedent-sources.md`를 따른다.
