# BE-147 의사결정 기록

사건 공개 조건에 신문 지면(`NO_PAPER`) 추가. COMMON-52(파이프라인 운영 켜기) 전에 필요하다. 담당 D(정민석), 리뷰 A(김해송, 관리자 화면).

## 문제 / 배경

- 공개 조건(A-13 표, `PublishReadiness`)은 공개 AI · 재판부 판결, 판단 요소, 개요 요소, 형벌 규칙 다섯 가지였다. 신문 지면은 조건이 아니었고, 관리자 화면이 "공개는 막지 않지만 메인 화면이 기본 지면으로 보여요" 경고만 띄웠다.
- 신문 지면은 1막 첫 화면(API 17)이고, BE-126부터 1막 해설(U1) 블록이 그 기사를 보고 만들어진다. 지면 없이 공개하면 사용자는 기본 지면을 보고, 대본은 승인 자체가 막힌다(A-13-11 `pending`에 `"PAPER"`).
- COMMON-52로 파이프라인 사건이 늘어나면 지면 없이 공개되는 사건이 실수로 생길 수 있어, 경고가 아니라 공개 조건으로 막는다.

## 검토한 대안

### 1. 막을까, 경고로 둘까

- 대안 A — 지금처럼 경고만 둔다: 관리자가 경고를 놓치면 기본 지면으로 공개된다. 파이프라인 사건이 늘면 실수가 잦아진다.
- 대안 B — 공개 조건으로 막는다 (**선택**): A-6 사유 목록과 A-13 409에 같은 코드로 나온다. 화면은 따로 경고를 둘 필요가 없다.

### 2. "지면이 있다"를 무엇으로 볼까

- 행이 있으면 있다 (**선택**): `case_paper.headline` · `article`이 NOT NULL(V21)이라 행이 있으면 내용도 있다. `existsByLegalCaseId` 한 번으로 판정한다.
- 기사 문단 수 · 헤드라인 길이까지 본다: DB 제약이 이미 보장하는 것을 다시 검사하게 된다. 빈 문단 같은 품질은 대본 검수(BE-126)의 몫이다.

### 3. 대표사진도 함께 막을까

- 막지 않는다 (**선택**): 대표사진이 없으면 사용자 화면이 공용 컷으로 돌아가 화면이 깨지지 않는다. 지면은 기본 지면이 사건과 무관한 내용이라 성격이 다르다.

### 4. 이미 공개된 사건

- 공개 조건은 공개할 때만 판정한다(A-13). 이미 공개된 사건은 그대로 둔다.
- 공개 사건은 지면을 고칠 수 없다(`guardNotPublished`). 지면이 없는 공개 사건은 공개 취소(A-13-14) → 지면 생성(A-13-6) → 재공개로 맞춘다. 대상과 시점은 팀 결정으로 남긴다(비공개 Jira 이슈 참고).

## 선택한 방법과 이유

- `PublishReadiness.of`에 `hasPaper`를 추가하고, 없으면 `NO_PAPER`를 다른 사유 뒤에 붙인다(기존 사유 순서를 바꾸지 않는다).
- `AdminReviewQueryService.readiness`가 `CasePaperRepository.existsByLegalCaseId`로 판정한다. A-6 표시와 A-13 확인이 같은 메서드를 쓰므로 한 곳만 고친다.
- 관리자 화면: `PUBLISH_REASON.NO_PAPER` 문구를 추가하고, 공개 섹션의 지면 경고는 사유 목록과 겹치므로 지웠다. 목 API도 같은 규칙을 따른다.
- API 명세 A-13 표 · v0.81에 반영했다(v0.79는 BE-140 3차 c, v0.80은 BE-129가 먼저 썼다).
- **"공개 전 확인"에 네 번째 항목을 더했다**(리뷰 반영): "신문 지면(제목 · 부제 · 본문)이 사건 사실과 맞고 판결 · 형량을 암시하지 않는지 읽어 확인했다". `NO_PAPER`는 지면이 **있다**만 보장하고, 사건 등록이 저장한 기사는 형식 · 지면 규칙만 통과했을 뿐 대본 자동 검수(BE-122) 대상이 아니다. 공개 뒤에는 지면을 고칠 수 없으므로(`guardNotPublished`) 공개 전에 사람이 읽게 한다. 문구는 대본 최종검수 체크리스트(`docs/script-final-review-checklist.md` 4번 기사 항목)와 맞췄다.

## 고려한 제약 사항

- 지면이 없는 비공개 사건은 이제 공개 버튼이 막힌다. 사건 등록 적재(A-14-1)는 대본 생성이 켜져 있고 전체 대본(`fullScript`)의 기사가 지면 규칙을 통과했을 때만 지면을 함께 저장한다(BE-126). 대본 생성을 꺼뒀거나 증거조사 대사만 있는 "준비 중" 대본(BE-107)은 지면이 자동으로 생기지 않는다.
- **지면 규칙을 통과하지 못해 지면 없이 등록된 사건**은 관리자가 A-13-6으로 지면을 만들면 공개 조건은 풀리지만, 대본 통승인이 막힌다. 통승인(BE-126)이 1막 해설(U1) 블록의 `basis.paper`(저장하지 못한 기사는 `null`)와 지금 지면 판을 비교하기 때문이다. 이 경우 사건은 **공개는 되지만 대본은 다시 등록해야 승인되는** 상태가 된다. 두 조건이 맞물린 결과이고, 해결은 BE-129 2차(U1만 다시 만들기)에서 한다.
- 관리자 문구는 "신문 지면을 만들어야 해요. (사진 · 지면에서 만들기)"로 정했다. 위치 안내는 공개 섹션 위 "바로 가기"의 이름(사진 · 지면)에 맞췄다.
