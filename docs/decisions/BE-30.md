# BE-30 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #73 본문.

## 문제 / 배경
- AI 판결 생성에 쓸 LLM을 공급자(OpenAI · Anthropic · Gemini)와 모델 단위로 바꿔 가며 비교할 수 있어야 했다.

## 선택한 방법과 이유
- 공급자 공통 호출 `llm.py`를 두고 표준 라이브러리(urllib)만 쓴다. 기존 도구의 "설치 없이 실행" 원칙을 유지하기 위해서다.
- 모델을 `공급자:모델ID`로 여러 개 지정해 회차마다 실행하고, 회차마다 검증까지 기록한다. 모델별 비교표(Markdown · CSV)를 자동으로 만든다.
- 프롬프트 해시를 `batch.json`에 남겨 다른 사건 · 프롬프트의 실행이 한 묶음에 섞이지 않게 막는다.
- 검색 · 그라운딩 도구는 붙이지 않는다(사전 학습 점검의 전제를 지키기 위해). API 키는 환경변수로만 읽고 기록에 남기지 않는다.
- 파이프라인 자동화(BE-31)에서 재사용하려고 `generate_runs()` 함수로 분리했다.

## 고려한 제약 사항
- 여러 공급자로 돌리면 비식별화한 사건 내용이 해당 공급자 모두에 전송된다(README에 주의 명시).
- 실제 API 호출은 PR 시점에 키가 없어 미확인이었다.
