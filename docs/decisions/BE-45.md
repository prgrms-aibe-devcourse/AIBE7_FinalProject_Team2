# BE-45 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #83 본문. 범위가 넓어진 경위는 Jira BE-45 코멘트.

## 문제 / 배경
- 비식별화(extract) · 재판부 초안(court)이 한 모델의 한도 · 과부하로 막히면 파이프라인 전체가 멈췄다.
- 점검 · 생성 단계는 무료 등급 모델이 일 한도에 걸리면 투표 인원이 줄었다.

## 검토한 대안
- 대안 A: 막히면 멈추고 사람이 모델을 바꿔 다시 돌린다.
- 대안 B: 모델 **목록**을 받아, 앞 모델이 과부하 · 요청 한도 · 일 한도 · 크레딧 소진으로 막힌 경우에만 다음 모델로 넘어간다.

## 선택한 방법과 이유
- 대안 B. 품질 문제(스키마 불일치 · 안전 필터 차단 · 인용 검사 실패 · 서비스 대상 아님)는 대체하지 않고 멈춘다. 대체 모델은 같은 입력으로 **처음부터** 다시 요청한다(부분 결과를 이어받지 않음).
- 점검 · 생성에는 `"free:<공급자>"`로 무료 모델을 자동 사용하게 했다. 막힌 모델의 자리는 대기 모델이 채우되 **독립 투표자**로 처음부터 `runs`회 기록하고, 대체 모델도 사전 학습 점검을 먼저 통과해야 참여한다.
- 판결문 원문을 보내는 extract · court는 원칙적으로 유료 키만 쓴다. 단 `allowFreeTierForJudgment`(기본 꺼짐)를 켜면 유료 모델이 모두 막힌 뒤 마지막 백업으로 무료 등급을 쓸 수 있다.

## 고려한 제약 사항
- 무료 등급은 입력을 제품 개선에 쓰고 사람이 검토할 수 있어 **데이터 정책 변경**에 해당한다. 팀이 "이미 공개된 판결문에 한해 허용"하기로 구두 합의했다(2026-10-08, 작성자 확인). 켠 설정 파일은 공개 판결문에만 쓰고, `report.json`의 `usedFreeTier`로 실제 사용 여부를 확인한다.
- `court.model`이 `null`이면 extract 목록을 그대로 쓰므로 extract에 켜면 court에도 같이 켜진다.
- 무료 모델 목록(`free_models.json`)은 공식 가격 문서(확인일 2026-10-08)를 요약 도구로 가져온 값이라 쓰기 전에 직접 확인이 필요하다.

## 추후 재검토가 필요하면
- 구두 합의는 문서로 남아 있지 않다. 정책을 바꾸거나 새 팀원이 합류하면 허용 범위를 다시 확인한다.
