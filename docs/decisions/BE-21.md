# BE-21 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #45 본문.

## 문제 / 배경
- Swagger UI와 `/v3/api-docs`를 로컬 · 개발에서는 보이고 운영에서는 숨겨야 했다.

## 선택한 방법과 이유
- `SWAGGER_ENABLED` 환경변수로 `springdoc.api-docs.enabled` · `springdoc.swagger-ui.enabled`를 함께 제어하고 **기본값을 꺼짐(`false`)**으로 뒀다.
- 운영에서 환경변수를 빠뜨려도 API 문서가 노출되지 않는 쪽(안전한 쪽)에 기본값을 둔다는 원칙이다. `FLYWAY_LOCATIONS`와 같은 방식이다.
- CI 테스트도 변수를 주지 않아 꺼진 상태로 돈다.

## 고려한 제약 사항
- 개발 서버 실행 설정에 `SWAGGER_ENABLED=true`를 넣는 작업은 설정 위치를 찾지 못해 이 PR에 포함하지 못했다(BE-21 완료 조건에 남김).
