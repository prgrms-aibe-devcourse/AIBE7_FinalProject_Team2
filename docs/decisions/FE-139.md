# FE-139 의사결정 기록

## 문제 / 배경

- 판결 체험 무대는 로컬 파일 `content/case-1/script.json`만 읽어, 실제 사건을 체험할 수 없었다.
- 서버는 대사만 단위 블록으로 저장해 API 18로 내려 준다(BE-126). 고정 문구 · 연출 · `section` · `confirm` · `slots`는 프론트 공통 틀(FE-33)의 몫이다.
- 순서 · 범위 · "서버 우선" 결정의 근거는 FE-139 Jira 댓글(2026-11-01 "해야 할 일 정리")이다. 나누는 기준은 아래 표로 옮겼다(FE-33 구상 초안 이관).

| 구분 | 맡는 곳 |
| --- | --- |
| 사건별 대사(U1 ~ U4), 배역, 마지막 질문 · 답을 고르는 값(`meta`) | 서버 API 18 |
| 기사 · 증거조사 사진 | 서버 API 17 |
| 판결 값(4 ~ 6막) | 각 화면의 서버 API |
| 민감 안내 | 무대 `attachNotice`(API 16 `sensitiveFlags`, FE-129) |
| 고정 문구 · 자리 · 모습 · 초점 · 절차 번호 · 카드 연결 | 프론트 공통 틀(`assembleScript.js` · `scriptFrame.json`) |

## 검토한 대안

- 공통 틀의 위치
  - 대안 A: 사건 1 대본의 1b · 4 ~ 6막을 그대로 import. 파일이 늘지 않지만, 비공개로 전환할 사건 1 대본에 실제 서비스가 묶인다.
  - 대안 B: 사건 내용이 없는 막만 `scriptFrame.json`으로 분리. 내용이 두 곳에 생기지만 사건 1 대본을 걷어 낼 수 있고, 어긋나면 테스트가 잡는다.
- 대본을 받는 시점
  - 대안 A: 막마다 화면이 API 18을 호출. 단순하지만 체험 중 서버 대본이 바뀌면 막 사이에 대사가 달라진다.
  - 대안 B: 받은 대본을 사건별로 메모리에 기억. 체험 중에는 같은 대본으로 끝까지 간다.
- 목 데이터
  - 대안 A: 블록 값을 별도 파일로 작성. 사건 1 대본과 내용이 중복된다.
  - 대안 B: 목이 사건 1 대본에서 대사를 뽑아 블록 모양으로 준다. 사건 1도 조립기를 지난다.

## 선택한 방법과 이유

- 공통 틀은 B. 1a · 2 · 3막은 대사 사이에 고정 문구가 끼므로 조립기 코드에, 대사가 없는 1b · 4 ~ 6막은 JSON에 둔다.
- 대본은 `utils/caseScript.js`의 `loadCaseScript`로 받고 성공한 값만 기억한다. "준비 중"은 곧 풀릴 수 있어 기억하지 않는다.
- 목은 B. 기본 배역에서 조립 결과가 사건 1 대본과 완전히 같은지 테스트하므로, 공통 틀이 무대와 어긋나면 바로 드러난다.
- 조립할 수 없는 응답(빠진 단위, `issue` · `admits`가 없어 마지막 질문 · 답을 고를 수 없음)은 추측해서 채우지 않고 "준비 중"으로 둔다. 고정 답의 뜻이 질문과 어긋나면 피고인의 진술이 틀리게 전달되기 때문이다.
- 배역은 법정 막(2 ~ 5막)만 따른다. 1막 · 6막은 법정 밖 안내라 사건마다 같다. 4 · 5막 틀은 기본 배역으로 적어 두고 반대 배역이면 두 이름을 맞바꾼다.

## 고려한 제약 사항

- `blocks` · `meta`는 BE-126 1차-2(PR #367) 이후 응답이다. 머지 전에는 실 API에서 조립할 수 없어 "준비 중"이 된다.
- 운영에 승인된 대본이 없다(`case_script` 0행). 사건 1을 하던 사용자도 무대 대신 대본 없는 화면을 본다(서버 우선 결정의 결과).
- 고정 문구가 `tools/ai-judgment/script_assembler.py`(검수 미리보기용)와 프론트 두 곳에 있다. 화면 기준은 프론트다.

## 추후 재검토가 필요하면

- 점검 모드(BE-126 2차): 지금 503은 일반 오류와 같이 "다시 시도" 안내다. `scriptStatus` · `SCRIPT_UNDER_MAINTENANCE` 안내는 2차 때 연결한다.
- 사건 1 비공개 전환: `SCRIPTS` · `scriptFor`(마이페이지 컬렉션, 목록 · 커뮤니티의 `scriptReady` 대체 판정)가 아직 로컬 대본을 본다. 전환할 때 함께 걷어 낸다.
