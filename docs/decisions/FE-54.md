# FE-54 의사결정 기록

> 근거: [#182 리뷰](https://github.com/prgrms-aibe-devcourse/AIBE7_FinalProject_Team2/pull/182), [FE-45 결정 기록](FE-45.md) "PR #180 리뷰 반영 — 결정한 것".

## 문제 / 배경
- FE-45(#180) 리뷰에서 지적됐지만 PR 범위 때문에 미룬 관리자 화면 중복 코드를 `adminKit.js`로 정리한다.
- 이슈에는 상세 보기 틀이 4개 페이지에 있다고 적혀 있었으나, 실제로 같은 틀이 있는 곳은 `adminMembersPage` · `adminPostsPage` 2곳뿐이었다. 신고 · 관리자 계정 화면에는 별도 상세 패널이 없다.

## 검토한 대안
- 대안 A: `detailPanel({ fetcher, draw, failText, active, unauthorized })`가 패널 노드와 `show(id)`를 돌려주는 방식
  - 호출하는 쪽은 `drawDetail`만 남기면 되고, 기존 `detail` 노드를 그대로 쓸 수 있다.
- 대안 B: 기존 `createLoader`에 상세 보기 모드를 추가
  - 목록 로더는 `seq`로 늦은 응답을 버리는 역할이라 책임이 달라서 합치면 복잡해진다.
- 라벨 헬퍼: `labeledField(text, control, hint)` / `checkField(text, control)` 두 개로 나눈다. 구조(label 안의 span + 입력칸 / 체크박스 + span)가 달라서 하나로 합치지 않았다.

## 선택한 방법과 이유
- 대안 A. 호출부 변경이 가장 작고, 흩어져 있던 UNAUTHORIZED 처리와 scrollIntoView를 한 곳에 모은다.
- `labeledField`에 hint가 있으면 `aria-describedby`로 입력칸과 연결한다. 이슈에서 요구한 "접근성 개선을 한 곳에서" 적용하는 첫 사례다. 사건 검수 화면(`adminCasePage`)의 `field()`가 hint를 쓰고 있어 이 화면이 첫 적용처다. 이미 `aria-describedby`가 있으면 지우지 않고 뒤에 붙인다.
- `reasonForm` · 회원 정지 기간 · 신고 처리 방법에 흩어진 같은 라벨 패턴도 `labeledField`로 바꿨다.

## 고려한 제약 사항
- `adminShell.js`의 로그인 이메일 · 비밀번호 칸은 FE-53(관리자 진입점)이 같은 파일을 고치고 있어 범위에서 뺐다. FE-53이 Merge된 뒤 후속으로 `labeledField`를 적용한다.
- 동작 변경 없음이 조건이라 문구 · 마크업 · 클래스 이름은 그대로 둔다.
- `detailPanel`은 먼저 연 상세의 늦은 응답이 나중에 연 상세를 덮지 않게 `createLoader`와 같은 `seq` 방식으로 막는다(리뷰 반영). 원래 코드에도 있던 문제를 헬퍼 한 곳에서 고친 것이다.
- 관리자 화면 테스트는 DOM 없이 도는 `node --test`지만, `element()`가 `document.createElement`만 쓰므로 작은 대역으로 `adminKit.test.js`를 추가했다.

## 회고 (PR #182 이후)
- 늦은 응답 덮어쓰기는 **브라우저 안의 응답 도착 순서 문제**라서 Redis · 메시지 큐 · DB 락 같은 서버 쪽 도구는 대상이 아니다. 서버는 요청마다 정확한 값을 돌려줬다.
- 브라우저 쪽 대안(AbortController · 로딩 중 클릭 막기 · 응답 id 비교 · TanStack Query) 중 변경이 가장 작고 `createLoader`와 일관된 `seq`를 택했다. 상세 조회는 읽기(GET)라 요청을 실제로 취소할 필요가 없다.
- 서버 쪽은 이미 사건 상태 변경 · 성향 재응시에 비관적 락(`FOR UPDATE`)을 쓰고 있어 이번에 손댈 것이 없었다. Redis는 캐시 · 토큰 저장소 용도이며 락으로 쓰지 않는다.
- 상세 비교표 · 재현 방법 · 서버 쪽 방법 정리는 [회고 · 트러블슈팅 문서](../troubleshooting/FE-54-detail-panel-race-condition.md)에 둔다.
