# FE-153 의사결정 기록

## 문제 / 배경
- 의견 보내기 창(`feedbackDialog.js`)은 창 크기가 바뀌면(`resize`) 닫힌다. 책상에서 날아온 펜이 열릴 때 계산한 자리에 고정되어 크기가 바뀌면 어긋나기 때문이다.
- 모바일(≤ 720px)은 메뉴 카드로 창을 열어 펜이 날아오지 않는데도 같은 규칙으로 닫혔다. 모바일 브라우저는 주소창이 접히고 펴질 때도 `resize`를 보내므로 창이 저절로 닫힐 수 있었다.

## 검토한 대안
- 대안 A: 높이만 바뀐 `resize`는 무시하고 폭이 바뀔 때만 닫는다. 주소창 문제는 막지만, 데스크톱에서 창 높이를 바꾸면 펜이 어긋난 채로 남는다.
- 대안 B: `resize` 때 펜 자리를 다시 계산한다. 정확하지만 날아온 펜이 쓰는 애니메이션(`fill: forwards`)을 다시 만들어야 해 코드가 커진다.
- 대안 C: 날아온 펜이 있을 때만 `resize`에 닫는다.

## 선택한 방법과 이유
- 대안 C. 닫는 이유가 "펜이 어긋난다" 하나뿐이라, 펜이 없으면(좁은 화면 · 연출 끔 · 동작 줄이기) 닫을 이유도 없다. 한 줄만 바뀌고 데스크톱 동작은 그대로다.

## 고려한 제약 사항
- 데스크톱(1440px) 동작은 바꾸지 않는다(FE-151 공통 지시).

## 추후 재검토가 필요하면 (선택)
- 721px 이상 터치 기기(태블릿)는 펜이 날아오므로 주소창 `resize`에 여전히 닫힐 수 있다. 실기기에서 문제가 되면 대안 A를 더한다.
