# COMMON-73 의사결정 기록

## 문제 / 배경
- COMMON-69 이미지의 좌우 방향을 검수했다. 화면은 "내로는 오른쪽, 남불은 왼쪽을 본다"를 전제로, 서 있는 곳에서 가운데를 보게 그림을 CSS로 뒤집는다(FE-128 `flipFor`). 전제와 반대로 그려진 컷(내로 피고인 감정 컷 등)은 사용자가 로컬 작업 폴더에서 바로잡았고, 이를 이미지 레포 · 본 레포에 옮겨야 했다.
- 물음표가 그려진 볼따구 컷 4장(볼따구 · 볼따구 슬림 `idle-thinking` × 내로 · 남불)은 뒤집으면 **물음표가 거울 글씨**가 된다. 4장 모두 오른쪽을 보고 있어 남불은 규칙 방향과도 반대였다.

## 검토한 대안
- 대안 A — 이 컷들은 뒤집지 않는다(반전 금지 목록): 물음표는 바르게 보이지만 자리에 따라 캐릭터가 바깥을 본다. 남불은 늘 규칙과 반대 방향이 된다.
- 대안 B — 반대 방향 그림을 따로 둔다(`-mirror`): 물음표만 떼어 몸을 뒤집고 물음표는 그대로 다시 붙인다. 화면은 뒤집어야 하는 자리에서 CSS 대신 이 그림을 쓴다. 파일이 늘고 고를 규칙이 필요하다.
- 대안 C — 반대 방향을 새로 생성: 같은 표정 · 같은 몸을 다시 얻기 어렵고 시간이 든다.

## 선택한 방법과 이유
- **대안 B**(사용자 결정: "물음표만 떼고 좌우 반전해서 다시 붙여"). 물음표는 몸과 떨어진 연결 영역 두 개(갈고리 · 점)라 알파 연결 영역으로 정확히 떼어진다. 결과는 연결 영역이 그대로 3개(몸 · 갈고리 · 점)여서 떼어 낸 찌꺼기가 없다.
- **기본 이름 = 규칙 방향, `-mirror` = 반대 방향.** 내로는 원본(오른쪽)이 기본이고 새 왼쪽본이 `-mirror`다. 남불은 새 왼쪽본이 기본이 되고 원래 오른쪽본을 `-mirror`로 바꿨다(원본을 지우지 않는다). 이렇게 하면 다른 컷과 같은 규칙(`flipFor`)을 그대로 쓰고, 뒤집어야 할 때만 그림을 바꾼다.
- 화면: `stage.js`의 `MIRRORED_LOOKS`(물음표 모습 목록) · `facedImage(who, look, flip)`가 뒤집어야 하는 자리에서 `-mirror.webp`를 고르고 CSS 반전을 끈다. 무대 캐릭터(`spr`) · 볼따구 해설(`cameo`) 두 곳에 건다. 다른 모습은 지금처럼 CSS로 뒤집는다.
- **`-mirror`는 일러스트 개수에서 뺀다.** 같은 그림의 방향만 다른 것이라 수집 · 대표 이미지 후보로 세면 안 된다. `update-manifest.sh`와 `IllustrationCatalogTest`가 같은 규칙(`*-mirror.webp` 제외)을 쓴다.
- 탐구 컷: 대체되어 `discard`에 있던 옛 공용 재연 컷 3장(`headline` · `sub-1` · `detail-1`)을 `cuts/inquiry`로 옮겨 `reporter` · `clue` · `sign`으로 이름을 붙였다(사용자 결정). 신문 여백 사진 목록(`newspaper.js`)과 대표 이미지 후보(`portraitPool.js`)에 더했다.
- webp 변환은 이미지 보관 규칙(6장)의 크기 · 품질 85를 따랐다. 역할 컷은 기존 파일과 같은 방식(표정 컷은 캔버스 그대로, 옛 컷은 여백을 잘라 높이 560)으로 맞췄다.

## 고려한 제약 사항
- 로컬 작업 폴더가 기준이다(사용자: "로컬 파일은 전부 정답"). 방향과 무관하게 바뀐 파일이 섞여 있어도 그대로 옮겼다.
- 다만 **지우는 일은 하지 않았다.** 로컬에 없고 이미지 레포에만 있는 사건 1 재연 컷(`reenact/case-1` 2장 · `_original` 4장)과, 로컬에만 있는 합성 작업 폴더(`reenact/composite` · `composite-noshadow`)는 반영하지 않았다(사건 1은 비공개 전환 예정, 합성본은 10/29에 폐기한 방식).
- 목 일러스트 총 개수(`authMockApi.js`)가 원래부터 실제 폴더와 1장 어긋나 있어 실제 기준(242장 · 사건 90장)으로 맞췄다.

## 추후 재검토가 필요하면
- 글자 · 기호가 든 컷이 더 생기면 `MIRRORED_LOOKS`에 모습을 더하고 `-mirror` 그림을 만든다(파일이 빠지면 `stage.test.js`가 실패한다).
- (11/03 반영 완료) 내로 변호인 역할 컷 · 노트북 · 데스크 펠트는 프롬프트(가이드 10-11 · B안 27-1 · 27-2)로 다시 뽑았다. 노트북은 화면 면에 생긴 흐릿한 얼룩을 화면 면만 균일하게 다시 칠해 고쳤다. 새 노트북은 그림이 캔버스를 거의 꽉 채워(이전 여백 약 6%) 화면 위치 CSS(`.laptop-art` 배경 크기 · `.laptop-screen`)를 다시 맞췄다. 변호인은 알파 영역 기준으로 잘라 판사 · 검사와 같은 크기(290 × 560)가 됐다.
- 이미지 레포의 사건 1 재연 컷(`reenact/case-1` 2장 · `_original` 4장)은 사용자 의도대로 삭제했다(비공개 전환 예정).
