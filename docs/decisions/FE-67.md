# FE-67 의사결정 기록

## 문제 / 배경
- 마이페이지 대표 이미지(프로필카드)의 캐릭터가 허리 아래부터 잘렸다. 원인은 그림 창의 그리드 행이 `auto`라 이미지의 `height: 100%`가 창 높이로 풀리지 않고 이미지 원래 높이(327px)가 되어, 창(201px)이 넘친 아래를 잘라 낸 것이었다.
- 성향카드와 대표 이미지가 비슷한 크기로 보여야 하고, 성향 이미지는 지금보다 조금 더 크게 보여야 한다. 그런데 성향 이미지(800 × 1000)는 캐릭터가 이미지 높이의 62 ~ 78%만 차지하고 투명 여백이 이미지마다 다르다(위 70 ~ 170px, 아래 127 ~ 240px). 역할 이미지(높이 560, 너비 266 ~ 368)는 여백이 거의 없다.

## 검토한 대안
- 대안 A: CSS만 고친다(창의 행을 고정해 `contain`). 잘림은 사라지지만, 이미지마다 여백이 달라 성향 이미지의 캐릭터가 작고 제각각으로 보인다.
- 대안 B: 불투명 부분(캐릭터)의 경계 상자를 재서(alpha bbox), 캐릭터가 창에서 같은 높이를 차지하도록 크기와 자리를 JS로 정한다(`utils/portraitFit.js`).
- 대안 C: 이미지 파일마다 여백을 잘라 다시 내보낸다. 이미지 32장 + 새 이미지마다 손이 가고, 담당(이미지 작업자)과 맞춰야 한다.

## 선택한 방법과 이유
- 먼저 **A**로 잘림을 없앴고, 성향 이미지를 직접 나란히 놓아 본 뒤(여백 차이가 눈에 띄었다) **B**를 더했다. C는 이미지 작업 흐름에 의존해 배제했다.
- 계산은 순수 함수(`fitPortrait`)로 두어 `node --test`로 검증하고, 캔버스를 쓰는 측정(`measureOpaqueBox`)과 반응형 재계산(`ResizeObserver`)은 브라우저 쪽 함수에 따로 둔다.
- 카드 비율을 7 / 12에서 7 / 14로 키워 그림 창을 키웠다(대표 이미지와 성향 이미지가 더 크게 보이게). 아치(둥근 위쪽)가 머리를 깎지 않도록 윗 여백(22px)을 둔다.

## 고려한 제약 사항
- 다른 출처 이미지(실제 모드의 CDN 등)는 캔버스를 읽을 수 없어 측정이 막힌다. 그때는 맞추지 않고 CSS 기본(`contain`)으로 보인다.
- 맞추는 동안은 크기가 튀어 보이지 않게 이미지를 가려 둔다(`.is-fitting`). 측정이 실패해도 이 클래스는 걷힌다.

## 추후 재검토가 필요하면
- 만난 모습 썸네일과 책갈피 얼굴에도 같은 크기 맞춤이 필요한지 본다(지금은 적용하지 않음).
