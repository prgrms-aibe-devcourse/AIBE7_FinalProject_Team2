# BE-44 의사결정 기록

> 소급 작성(COMMON-39). 근거: PR #82 본문.

## 문제 / 배경
- 무료 등급 모델은 분당 한도가 낮아, 한 모델을 연달아 부르면 한도에 걸렸다.

## 선택한 방법과 이유
- 사전 학습 점검 · 생성 호출을 모델 교차 순서(`m1 1회, m2 1회, m1 2회 …`)로 바꿨다. 같은 모델의 호출 간격이 (모델 수 × `delay`)로 늘어 한도를 분산한다.
- 모델은 **독립된 투표자**로 유지한다. 기록 경로 · 회차 번호 · 점검 판정 · 합의 선택 기준은 그대로이고, 다른 모델이 대신 생성하지 않는다(투표 결과를 흐리지 않기 위해).
- 일 한도가 소진된 모델은 이후 순서에서 빠지고 나머지는 계속 진행한다. 재생성도 해당 모델들을 묶어 교차 순서로 돌린다.

## 고려한 제약 사항
- 생성 단계 중 예외가 나면 `PipelineError` 출력의 `models` 요약이 비어 있다(기존에는 끝난 모델분이 들어갔음). API 키는 호출 전에 모두 확인하므로 키 누락은 첫 호출 전에 멈춘다.
