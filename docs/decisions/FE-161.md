# FE-161 의사결정 기록

## 문제 / 배경
- 모바일(≤ 720px) 신문 면 탭 줄(면이 아홉)과 면 색인 줄은 가로로 밀어 고르는데 뒤에 더 있다는 표시가 없었다.
- "지금 면을 줄 가운데로" 계산이 세 곳에 따로 있었다(`newspaperFront.js` · `caseListPage.js` · 성향 테스트 쪽은 FE-156 리뷰에서 제거). PR #405 리뷰에서 공용 함수로 모으자는 제안이 있었고 이 이슈로 미뤘다.

## 검토한 대안
- 표시 방식(390px 화면 4종을 나란히 비교)
  - A. 끝쪽 44px가 종이색으로 옅어진다(`mask-image`).
  - B. 끝쪽에 접힌 종이 같은 안쪽 그늘. 말려 들어가는 느낌이지만 얼룩처럼 보인다.
  - C. 흐림 + 꺾쇠 `›`. 가장 분명하지만 글자 장식이 하나 더 생긴다.
- 구현 위치: 줄마다 CSS · JS를 따로 / 공용 도우미 한 곳.

## 선택한 방법과 이유 (사용자 결정: A)
- 표시는 A. 집무실 은유에 새 물건을 더하지 않고, 끝까지 밀면 사라져 "다 봤다"가 전달된다. 꺾쇠가 필요하면 나중에 A 위에 얹을 수 있다.
- 구현은 공용 도우미 `utils/scrollStrip.js`(`centerInStrip` + `watchStripEdges`). 줄이 화면에 붙은 뒤 한 번 가운데를 맞추고 `scroll` · `ResizeObserver`로 `data-more-start` / `data-more-end`만 갱신한다. 흐림 CSS는 속성만 보므로 `style.css`에 한 번만 두어 새 줄도 도우미만 부르면 된다. 면을 바꿔 다시 그리는 줄은 감시를 `WeakSet`으로 한 번만 붙인다.

## 고려한 제약 사항
- 사파리: `mask-image`에 `-webkit-` 접두사를 함께 쓴다.
- 흐림은 줄 전체에 걸리므로 가장자리 44px 안의 탭은 반쯤 옅게 보이지만 눌림 · 접근성은 그대로다(시각 효과뿐).
- 관리자 메뉴(`adminShell.js`)의 가로 스크롤 줄과 커뮤니티 슬라이드는 이번에 옮기지 않았다(관리자는 FE-159에서 다룬 별도 틀, 슬라이드는 스냅 동작이 달라 가운데 맞춤 대상이 아니다).

## 추후 재검토가 필요하면
- 실기기(사파리)에서 흐림 마스크가 스크롤 중 끊기지 않는지 확인한다. 끊기면 마스크 대신 가장자리에 그라데이션 덮개 요소를 둔다.
