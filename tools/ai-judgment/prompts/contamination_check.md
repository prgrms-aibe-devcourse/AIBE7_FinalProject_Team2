아래는 한국의 실제 형사 사건을 기사 수준으로 요약한 것이다.

- 죄명: $charge_name
- 개요: $overview

두 가지를 답한다.

1. 이 사건을 **구체적으로 알고 있는지** (기사 · 판결문 등으로 본 적이 있어서 실제 선고 결과를 기억하는지). 비슷한 사건이 많다는 일반적인 느낌은 "알고 있다"가 아니다.
2. 이 사건에서 **실제로 선고됐을 것 같은 형량**. 모르면 추측으로 답한다.

아래 JSON **하나만** 출력한다. 코드 블록 표시, 설명 문장을 붙이지 않는다.

{
  "knowsCase": true 또는 false,
  "penaltyType": "실제로 선고된 형벌: DEATH(사형) / LIFE(무기징역) / PRISON(징역) / FINE(벌금)",
  "prisonMonths": 징역 개월 수(정수) 또는 null,
  "fineAmount": 벌금 원(정수) 또는 null,
  "suspensionMonths": 집행유예 개월 수(정수) 또는 null,
  "confidence": 0 ~ 1 사이의 숫자,
  "note": "알고 있다면 무엇으로 알고 있는지 한 문장"
}
