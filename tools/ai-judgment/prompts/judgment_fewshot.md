# 예시 (형식 참고용)

아래는 **출력 형식과 이유 쓰는 방식**만 보여 주는 가상 예시다. 죄종이 다른 지어낸 사건이고, 형량 값은 일부러 `⟨형량⟩`으로 가렸다.
예시의 사건 · 판단 · 형량을 이 사건에 옮기지 않는다. 실제 답에서는 `⟨형량⟩` 자리에 정수를 쓰고, 코드 블록 없이 JSON만 출력한다.

## 예시 입력 (요약)

- 죄명: 사기 (고정값). 선고할 수 있는 범위: 징역 · 벌금
- 사건: 중고 거래 앱에서 물건을 보낼 생각 없이 여러 사람에게 돈을 받았다. 피해자 일부와 합의했고, 같은 범행으로 처벌받은 적이 있다.
- 판단 요소 목록: 1. 여러 사람을 상대로 반복했다 / 2. 같은 범행 전력이 있다 / 3. 피해자 일부와 합의했다 / 4. 범행을 모두 인정했다 / 5. 생활고를 이유로 들었다
- 유사 판례: 반복 거래 사기에서 전력이 있으면 실형, 합의가 많으면 형을 낮춘 판례가 제공됨

## 예시 출력

{
  "penaltyType": "PRISON",
  "reducedTo": null,
  "prisonMonths": ⟨형량⟩,
  "fineAmount": null,
  "suspensionMonths": null,
  "factors": [
    { "factorId": 1, "direction": "UP", "reason": "여러 피해자를 상대로 같은 수법을 반복해 계획성이 크다." },
    { "factorId": 2, "direction": "UP", "reason": "같은 범행으로 처벌받은 뒤에도 다시 범행했다." },
    { "factorId": 3, "direction": "DOWN", "reason": "피해자 일부와 합의해 피해가 일부 회복됐다." },
    { "factorId": 4, "direction": "DOWN", "reason": "수사 단계부터 범행을 모두 인정했다." }
  ],
  "reasoning": "반복된 범행과 같은 범행 전력은 무겁게 보았다. 제공된 유사 판례처럼 전력이 있는 반복 범행이라 실형을 선택했지만, 이 사건은 일부 피해자와 합의한 점이 판례와 달라 형을 그보다 낮췄다. 생활고 주장은 범행 경위로만 보고 형을 낮추는 사정으로 삼지 않았다.",
  "summary": "반복 범행과 전력을 무겁게, 일부 합의를 함께 본 판단",
  "referenceTags": ["형법 제347조 제1항", "사기범죄 양형기준", "유사 판례 2건"]
}

- 고려하지 않은 요소(5번)는 `factors`에 넣지 않았다.
- 유사 판례는 **공통점 · 차이점**을 이유에 녹였고, 판례 형량을 그대로 따르지 않았다.
