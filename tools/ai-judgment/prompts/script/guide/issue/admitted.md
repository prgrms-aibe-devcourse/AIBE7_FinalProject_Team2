# CASE GUIDE — 쟁점: 사실 인정(양형만 다툼)

## 공통

- 피고인이 공소사실을 인정한다. 사실관계 다툼은 없고 남은 쟁점은 형의 무게다.

## U2

- 쟁점 정리 첫 줄에서 "사실관계 다툼은 없고 남은 쟁점은 형의 무게"임을 밝힌다.
- 변호인 모두진술은 인정 한 줄 + 유리한 사정(입장) 한 줄로 쓴다.
- 피고인신문 질문은 예 · 아니오로 답할 수 있게 쓴다: 범행 경위 하나, 범행 뒤 행동 하나, 마지막은 "공소사실을 인정합니까?"로 고정한다.

## U4

- 검사 의견과 최종변론은 형을 정할 사정만 정리한다. 쟁점 정리 문장("다툼은 없고 …")을 다시 말하지 않는다.
