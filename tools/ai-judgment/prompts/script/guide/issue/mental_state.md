# CASE GUIDE — 쟁점: 정신상태(책임능력)

## 공통

- 정신상태(심신미약 등)가 쟁점이다. 공소사실 자체를 인정했는지는 사건 데이터대로 따로 밝힌다(인정 사건이면 "사실관계 다툼은 없고 책임능력이 쟁점").
- 진단 · 감정 결과는 사건 데이터의 표현을 그대로 쓴다. 질환을 범행의 원인으로 단정하지 않는다.

## U0

- 설계도의 신문 질문에 정신상태 · 진단 · 치료 이력을 묻는 질문을 넣지 않는다(답변으로 내면 · 병력을 말하게 된다). 범행 경위 · 범행 뒤 행동 같은 사실만 묻고, 마지막은 공소사실 인정 여부로 둔다.

## U2

- 쟁점 정리에서 책임능력이 쟁점임을 한 줄로 밝힌다.
- 피고인신문에 정신상태 · 진단 · 치료 이력을 묻는 질문을 넣지 않는다(답변으로 내면 · 병력을 말하게 된다). 이 쟁점은 쟁점 정리와 증거로만 다룬다.

## U4

- 변호인의 책임능력 주장은 주장 문형으로 쓰고, 형이 가벼워질 것이라고 암시하지 않는다.
