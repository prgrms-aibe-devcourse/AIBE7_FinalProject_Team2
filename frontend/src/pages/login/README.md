# login

**S-12 로그인** 화면 틀이다 (FE-52, IA 4장 `/login`). 회원가입(`/signup`, FE-104)도 여기 있다.

| 파일 | 내용 |
| --- | --- |
| `loginPage.js` | `renderLoginPage(container, { api, navigate })` — 화면을 그린다 |
| `authCallbackPage.js` | `/auth/callback` 카카오 로그인 콜백 (FE-74) — M-1 재발급으로 첫 토큰을 받고 "카카오 회원"으로 로그인 표시, `?error=` · 재발급 실패면 안내 |
| `login.css` | 로그인 화면 스타일 (404 서류 한 장 모양도 여기, FE-104) |
| `signupPage.js` | `renderSignupPage(container, { api, navigate })` — 회원가입 화면 (FE-104) |
| `signupRule.js` | 회원가입 입력 규칙(아이디 · 비밀번호 · 닉네임 · 동의). `signupRule.test.js`로 확인 |
| `loginParts.js` | 로그인 · 회원가입이 함께 쓰는 카카오 버튼 · 요청 중 표시 |
| `loginDesk.js` | 나뭇결 책상 + 펠트 패드 + 펜 틀. 로그인 · 콜백 · 404(`app/notFoundPage.js`)가 함께 쓴다 |

## 구성

- 모양 (FE-69): 메인 책상과 같은 나뭇결 위에 네이비 펠트 데스크 패드를 놓고, 오른쪽에 펜(장식)을 걸쳐 둔다. 로그인됨 · 카카오 콜백 화면도 같은 패드를 쓴다(`loginDesk`). 연출은 없다. 개발 서버의 목 모드에서는 오른쪽 아래(좁은 화면은 패드 아래)에 개발용 "넘어가기" 버튼 줄(`loginDevJump.js`)이 붙는다. 배포 빌드에는 붙지 않는다(FE-104).
- 공통 헤더 → 가운데 카드: 제목 · "로그인하지 않아도 모든 판결 체험을 할 수 있어요"(REQ-003) · 카카오 로그인 버튼 · 또는 · 아이디 · 비밀번호 폼 · "처음이신가요? 회원가입" · 로그인 없이 사건 보러 가기. 폼은 실제 모드에서도 펼쳐 둔다(FE-104).
- **관리자 로그인 (FE-53)**: 아이디 · 비밀번호는 관리자 로그인(A-1 · A-2)을 먼저 시도한다(`adminLogin.js`). 성공하면 마이페이지 자리가 관리자 페이지가 된다. 목 모드에서는 `admin`으로 시작하는 아이디만 관리자로 시도한다. 사용자 로그인이 없는 실제 모드에서는 카카오 없이 이 입력칸만 보인다.
- **목 모드**는 개발용 목업 로그인(`mocks/authMockApi.js`)이 받아 어떤 값이든 로그인되고, 카드에 "개발용 목업 로그인" 안내가 붙는다. **실제 모드**의 카카오 버튼은 M-3(`/api/v1/auth/oauth2/authorization/kakao`)으로 브라우저를 이동시키고(FE-74), 아이디 · 비밀번호는 관리자 로그인만 된다.
- 로그인하면 닉네임을 `utils/session.js`에 두고 메인으로 간다(로그인 화면은 기록에서 바꿔치기해 뒤로 가기로 돌아오지 않는다). 공통 헤더의 "로그인" 자리에 닉네임이 나오고, 누르면 마이페이지(S-17)로 간다. 닉네임이 길면 줄여 보인다.
- **회원가입 (FE-104)**: 카카오로 시작하기 + 아이디 · 비밀번호 · 비밀번호 확인 · 닉네임 · 필수 동의. 목 모드는 목업 가입(`authMockApi.js signup`, `admin`으로 시작하는 아이디는 중복으로 보임)으로 바로 로그인된 상태가 된다. 실제 모드는 회원가입 API가 아직 없어 입력 검사 뒤 준비 중이라고 알리고, 카카오로 시작하기만 된다. API가 생기면 `realApi.js`에 같은 이름 `signup({ id, password, nickname })` → `{ nickname }`으로 붙인다(중복 아이디는 `DUPLICATE_ID`).
- 이미 로그인한 채로 `/login`에 오면 누구로 로그인했는지와 마이페이지 · 로그아웃을 보여 준다. 로그아웃은 마이페이지 맨 아래에도 있다.
- 빈칸으로 제출하면 오류 문구(`role="alert"`)를 보여 주고 첫 빈칸으로 포커스를 옮긴다(`aria-invalid`). 카카오 버튼은 카카오 디자인 가이드 색(`--color-kakao`)을 쓴다.
- 토큰: 액세스 토큰은 `api/client.js` 메모리에만 두고, 401이면 M-1 재발급을 한 번 한 뒤 다시 요청한다. 재발급이 401이면 로그인 표시를 지운다. 로그아웃(M-2)도 토큰을 버린다.
