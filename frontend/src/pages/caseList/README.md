## 사용하는 API

`api` 객체로 주입받는다. (지금은 [`mocks/`](../../mocks/README.md)의 목 구현)

| 호출 | API | 동작 |
| --- | --- | --- |
| `api.getCases(crimeType)` | API 1 `GET /cases` | 사건 목록. 범죄 유형 면(`MURDER` · `FRAUD` · `INJURY` · `ROBBERY` · `THEFT`)은 그 유형으로 거르고, 나머지 면은 전체 목록을 받는다(면 정의의 `apiType`) |

- **기사 고르기 (FE-32, 흐름 목업 ②)**: 책상(S-01)에서 집어 든 신문이다. 지면 오른쪽 위에 남불의 안내(오늘 지면의 사건 수)를 적은 정사각형 포스트잇이 붙어 있고(FE-56에서 왼쪽 → 오른쪽), 누르면 떼어져 날아간다(FE-50, 포커스는 첫 탭으로). "신문 내려놓기" 버튼은 없앴다(FE-50) — 책상으로는 정보 줄 왼쪽의 "← 메인으로"와 Esc로 간다(FE-56: "처음으로" · "서비스 소개"는 뺐다). 위에는 모든 화면과 같은 공통 헤더가 붙는다(라우터). 기사(머리기사 제목 · 사진 · 머리기사 단 · 추천 · 다른 사건)를 누르면 그 기사의 제목이 S-20 사건 정보의 큰 제목 자리로 커지며 날아간다(FE-118, `utils/articleZoom.js` — 지금 지면을 본뜬 한 장을 띄워 두고 `navigate('caseDetail', { caseId, from: 'paper' })`, S-20이 제목을 받는다). 머리기사 단 · 사진을 누르면 머리기사 배너 제목이 날아간다. 움직임 줄이기면 연출 없이 바로 간다. 키보드 · 화면 낭독기는 기사 안의 "사건 펼쳐 보기" 버튼으로 고른다. **체험 시작 · 이어서 하기는 S-20에서 한다**(API 명세 5장 S-02 확장). Esc는 책상으로.
- **면 넘기기 (FE-118)**: 유형 탭 하나가 신문 한 면이다(전체 = 1면 → 살인 · 사기 · 상해 · 강도 · 절도). 탭 말고도 키보드 ← →(글자 칸 · 수정 키 제외), 손가락 밀기(`utils/newspaperFaces.js` `swipeStep`)로 넘긴다. 뒤 면으로는 한 장이 오른쪽에서 왼쪽으로 넘어가고, 앞 면으로는 거꾸로 앞 면이 왼쪽에서 넘어와 덮는다(`pageTurn.js` `back`). 키보드 · 밀기로 넘기면 새 면은 맨 위부터 보인다. 종이 귀는 FE-119에서 뺐다. 양옆 화살표(넓은 화면, 마우스용이라 낭독기 · 탭 순서에서는 뺀다)는 남겼다(넘김은 탭 · 양옆 화살표 · ← → · 밀기). 기사를 누르는 것은 언제나 사건 정보로 가는 길이고 넘김은 이 조작으로만 한다. 면은 지금처럼 주소 `?type=`에 남는다(replaceState — 면마다 방문 기록을 쌓지 않는다).
- **면 구성 (FE-119)**: 탭 하나가 신문 한 면이다. 1면(헤드, 머리기사 1 + 추천 2 + 다른 사건 6 = **9건만**) → 살인 · 사기 · 상해 · 강도 · 절도(**사건이 0건인 면은 숨긴다**, 지금 보는 면은 남긴다) → **색인**(전체 사건을 제목만 주르륵, 제목 · 키워드 검색) → **성향 테스트** · **오피니언**(자리와 링크만 있는 껍데기). 면마다 다른 정책은 면 정의(`faces.js`, FE-123 — 아래 "면 추가하기")에, 면 계산은 `utils/newspaperFaces.js`(`visibleFaces` · `layoutCases`)에 있다. 범죄 유형이 아닌 면(색인 · 성향 테스트 · 오피니언)은 API에 유형을 보내지 않고 전체 목록(`getCases()`)을 받는다. 우상단 귀는 어느 면에서나 "오늘의 사건 n건"만 보인다(왼쪽 귀와 같은 높이). 유형 면은 9건 뒤의 사건을 **"이 면 더 보기"**(같은 종이가 아래로 펼쳐지는 점선 줄)로 연다. 신문 최소 높이는 `max(100dvh + 120px, 신문 폭 × 1.4)`이라 짧은 면은 법적 고지가 아래로 밀리고, 펼침으로 종이가 늘어나는 모습은 대개 화면 밖에서 일어난다(S-20 기사 지면은 제외). 1면 아닌 모든 면은 안쪽 면(`.inner-page`) 모양이다.
- **다른 화면에서 특정 면으로 열기 (FE-119)**: 옵션 `openAt`(`navigate('list', { openAt: 'INDEX' })`)로 면을 정해 열 수 있다. 주소 `?type=`에 남기고 기록의 넘김값은 비워 새로고침으로 되풀이되지 않는다(S-20 지면 목차 8면이 쓴다).
- **세로 여백 채움 (FE-119)**: 신문 최소 높이(`max(100dvh + 120px, 신문 폭 × 1.4)`)보다 기사가 짧으면 남는 높이를 읽을거리 줄로 채운다. 본문(`.front`)이 남는 높이를 받고 그 안의 `.face-fill`은 기사 높이와 상관없이 남은 만큼만 차지하므로(flex-basis 0) 높이 · 폭을 재서 `planFiller`가 줄 수(최대 2) · 칸 수(폭 360px당 1칸, 최대 4)를 정하고, 사진이 늦게 오거나 창 크기가 바뀌면 `ResizeObserver`로 다시 짠다. 줄 높이가 남는 높이를 나눈 값이라 빈틈이 없다. 높은 줄(190px 이상)은 사진 지면을 대각선으로 엇갈려 섞는다. 기사 칸 안의 빈 칸과 같은 덱(`createFillerDeck`)에서 뽑아 한 면 안에서 같은 지면이 되풀이되지 않고, 광고는 면당 한 번이다(다시 짜도 같은 결과가 나오게 `fork()`로 이어 뽑는다).
- **빈 칸 채움 (FE-118)**: 기사가 모자라 비는 칸을 사건이 아닌 작은 지면으로 채운다. 추천 사건이 한 건뿐이면 비는 반쪽에 세 개를 세로로, "이번 호 다른 사건" 마지막 줄의 빈 칸(넓은 화면 6칸 기준 `emptySlots`, 태블릿 3칸 · 모바일 2칸에서 남는 뒤쪽 칸은 CSS가 숨긴다), 다른 사건이 아예 없는 면은 아래에 세 칸 한 줄. 내용은 법정 상식(1막 막간과 같은 `content/courtFacts.json`)과 판결 성향 테스트 광고(누르면 신문 버전 `/test/paper`)이고, 둘 이상이면 맨 앞 하나가 광고다. 눌러도 사건으로 가지 않는다.
- 책상에서 왔으면(`from: 'desk'`) 메인 책상에서는 지면이 화면 아래에서 올라오고 뒤에 남긴 책상이 흐려진다(FE-50, `.is-rising` · `.paper-ghost`). 올라오는 도중 기사가 채워져 끊기지 않게, 사건 목록을 그리고 첫 사진들을 디코딩할 때까지(최대 1.2초) 지면은 아래에 멈춰 두었다가 한 번에 올린다(`.is-going`). 좁은 화면 메뉴 · 비교 화면에서 왔으면 지면이 한 번 다가오며 나타난다(`.is-arriving`). 메인 맨 아래 신문 끝자락에서 왔으면(`from: 'tail'`, FE-87) 같은 방식으로 메인을 뒤에 남겨 두고, 메인이 본떠 넘긴 끝자락이 곧바로 위로 잡아당겨지며 커지고, 들어 올린 뒤 그 밑에서 같은 자리 · 같은 폭 · 같은 기울기로 함께 움직이던 이 지면으로 넘어가 제자리로 온다(`.is-spreading`, `spread` → `utils/tailSpread.js`). 넘어가기 직전까지 다 그려지지 않았으면 그 자리에서 기다린다. 새로고침 · 뒤로 가기로는 되풀이하지 않는다. 움직임 줄이기면 연출 없이 바로 바뀐다.
- **FE-102 (critique 반영)**: 사건 순서는 지금 체험할 수 있는 사건이 먼저, 그다음 참여 많은 순이다(머리기사 · 추천 칸에 "준비 중"이 앞서지 않게). 포스트잇 문구는 체험 가능한 사건 수에 맞춘다. 고른 유형 탭은 주소 `?type=`에 남고(replaceState), 탭에는 건수 글자가 붙고 요약은 고른 면에 맞춰 바뀌며, 탭을 눌러도 포커스가 새로 그린 같은 탭에 남는다. 목록을 받기 전 · 오류에서도 탭 줄을 그대로 둔다(로딩 중에는 누를 수 없고, 아래 푸터 · 안내는 감춰 CLS를 없앴다). 포스트잇은 떼기 전에는 오른쪽 귀를 감추고, 같은 사건의 제목 · 사진 · 기사 단은 호버를 함께 보인다.
- **진행 상태 도장 (FE-19, REQ-010 · FR-1-6, 도장은 FE-119)**: API 1의 `myStatus`로 분류명 줄 오른쪽에 지면에 찍힌 작은 도장(이중 테두리, -4도)을 찍는다. `IN_PROGRESS`는 "진행 중"(남색), `COMPLETED`는 "완료"(회색)이고, 체험 전(`null`) · 준비 중 사건에는 아무것도 찍지 않는다("준비 중" 글자 배지는 없앴다. 준비 중은 정렬에만 쓰고 S-20 도장이 알린다). 세부 상태(7단계)는 목록에 보이지 않는다. 색인에서는 줄 오른쪽에 찍는다. 건수 요약 줄("상해 3건 · 전체 11건")과 색인의 "(3면에 계속)"도 없앴다(색인은 제목 자체가 사건으로 가는 버튼). 성향 테스트 면 · 광고는 신문 버전(`/test/paper`)으로 들어간다. 신문 최소 높이는 `max(100dvh + 120px, 신문 폭 × 1.4)`다.
- 신문 1면 구성(FE-18, 시안 v12): 참여 많은 순으로 첫 사건이 머리기사(배너 제목 · 메인 사진 · 오른쪽 머리기사 단), 다음 2건이 추천 사건, 나머지는 "이번 호 다른 사건" 띠로 간다. 사건 수가 적거나 유형 탭으로 거르면 있는 만큼만 그린다.
- **공개 범위**: 목록은 처음 판단(S-03) 전 화면이라 사건 정보는 제목 · `shortIntro` · `keywords` · `crimeCategoryLabel` · `participantCount`만 쓴다. 상세 사실 · 판단 요소 · 양측 주장 · 형량은 쓰지 않는다. 머리기사 안내 글과 추천 사건의 [알아두기]는 사건과 무관한 고정 문구(`LEAD_GUIDE` · `TYPE_NOTES`).
- 기사 제목 · 부제 · 본문은 `headline` · `deck` · `article`(문자열 배열)을 쓴다. **API 1에 아직 없는 제안 필드**라 지금은 목 데이터에만 있고, 값이 없으면 사건 제목 · `shortIntro`와 고정 문구로 채운다. 본문은 S-03 사건 개요 수준의 사실만 쓴다.
- 이미지가 없으면(`thumbnailUrl`이 `null`) 유형별 연출 이미지(`public/images/case-*.svg`)를 쓴다. 난이도 · 예상 시간은 표시하지 않는다.
- 공통 헤더 대신 신문 제호를 그리고, 법적 고지는 공통 푸터([`components/siteLayout.js`](../../components/siteLayout.js))를 지면 맨 아래에 붙인다.
- 요청 · 응답 형식은 [API 명세서](../../../../docs/api-specification.md) API 1을 따른다.

## 면 추가하기 (FE-123)

면 하나는 `faces.js`의 `FACES` 목록 항목 하나다. 화면(`caseListPage.js`)은 지금 면 열쇠(`selected`)로 이 정의를 찾아 그대로 따르고, 면 이름으로 분기하지 않는다.

| 속성 | 뜻 | 기본값 |
| --- | --- | --- |
| `key` | 면 열쇠. 주소 `?type=` · 탭 `data-type` · `openAt`에 쓴다. 1면만 `undefined` | (필수) |
| `label` | 탭 이름 | (필수) |
| `name` | 양옆 화살표 제목에 쓰는 이름("살인면") | `label` |
| `view` | 본문 모양. `caseListPage.js`의 `FACE_VIEWS` 이름(`cases` · `index` · `test` · `opinion`) | (필수) |
| `apiType` | API 1에 보낼 범죄 유형. 없으면 전체 목록 | `undefined` |
| `front` | 1면(9건만 · 머리기사 표시 · 안쪽 면 모양이 아님) | `false` |
| `count(summary)` | 탭 옆 건수. `null`이면 달지 않는다 | `() => null` |
| `hideWhenEmpty` | 건수가 0이면 탭 · 넘김에서 숨긴다(지금 보는 면은 남김) | `false` |
| `tip({ total, playable })` | 포스트잇 문구. 전체 목록을 받는 면만 체험 가능 건수(`tipMessage`)를 말한다 | 전체 건수만 |
| `fill` | 면 아래 세로 여백을 읽을거리로 채운다. 전용 내용으로 높이가 차는 면은 `false` | `true` |

1. **이미 있는 모양의 면**(예: 새 범죄 유형): `FACES`의 넘김 순서 자리에 `crimeFace('KEY', '이름')`처럼 한 줄을 더한다. 탭 · 화살표 · ← → · 밀기 · 주소 `?type=` · `openAt`이 모두 이 목록을 따른다.
2. **새 모양의 면**(예: 오피니언에 실제 사설): `caseListPage.js`의 `FACE_VIEWS`에 `이름: (face, ordered) => [지면 조각들]`을 더하고, 면 정의의 `view`를 그 이름으로 바꾼다. `ordered`는 정렬된 사건(체험 가능 → 참여 많은 순)이고, 기사처럼 누르면 사건 정보로 가게 하려면 `pickable(node, item)`을 쓴다. 칸이 비면 `fillers(n)`으로 채운다.
3. 그 면이 전용 내용으로 높이를 채우면 `fill: false`로 세로 여백 채움을 끈다(신문 최소 높이는 그대로).
4. `faces.test.js`에 순서 · 건수 · 문구 기대값을 고친다.
