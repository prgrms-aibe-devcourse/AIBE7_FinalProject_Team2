# landing

**S-01 메인 — 판사의 책상** 화면이다 (FE-18, 시안 "B안 일러스트 · C안 구도", 2D 평면).

| 파일 | 내용 |
| --- | --- |
| `landingPage.js` | `renderLandingPage(container, { api, navigate, section })` — 화면을 그린다 |
| `landing.css` | 메인 화면 스타일 (책상 일러스트 · 메뉴 카드 · 서비스 소개 = 집무실 바닥) |

## 구성

- **책상 위 물건이 메뉴다.** 이름표(메모지)는 붙이지 않는다(FE-50에서 없앴다). 물건 이름은 낭독기(`aria-label`)와 좁은 화면 메뉴 카드에 쓴다.

  | 물건 | 메뉴 | 이동 | 상태 |
  | --- | --- | --- | --- |
  | 신문 | 실제 사건 판결 체험 | 신문 집어 들기 → `navigate('list', { from: 'desk' })` → S-02 | 동작 |
  | 서류철 | 판결 성향 테스트 | 철이 화면 아래에서 올라옴 → `navigate('test', { from: 'desk' })` → S-15 | 동작 |
  | 커피잔 | 마이페이지 | 커다란 잔이 우상단에서 날아와 섰다가 오른쪽으로 빠져나감(`utils/coffeeDive.js`) → `navigate('me', { from: 'mug' })` → S-17 | 동작 |
  | 펜 | 의견 보내기 (FE-50, 휴대폰 자리) | 범위 밖 | 곧 열려요 |
  | 노트북 | 커뮤니티 | 눈을 감았다 뜨듯 위아래로 닫혔다 열리며 커뮤니티가 나옴 — 컴퓨터 부팅(`utils/laptopBoot.js`, FE-47) → `navigate('community')` → S-18 | 동작 (목 모드) |

  화면이 생기면 `landingPage.js`의 `OBJECTS`에서 그 물건의 `route`에 화면 이름(`routes.js`의 `name`)만 넣는다. 누르기 가능 여부가 함께 바뀐다.
  책상 위 포스트잇은 내로를 가린 한 장(`--postit`, 접착면 띠)뿐이다. 서류철 그림 위 라벨은 "3분 성향검사".
- **신문 지면은 사건 목록 API(API 1)로 채운다.** 참여 많은 순 첫 사건이 머리기사(제목 · 부제 · 첫 문단 · 사진), 다음 2건이 아래 기사(S-02 추천 사건과 같은 사건 사진 16:9 → 제목 → 문단을 이어 4줄까지)다. 지면에는 이 3건만 싣고, 아래 기사 단은 지면 끝까지 내려가 가운데 세로 괘선이 길게 이어진다(남는 곳은 여백). 신문은 실제 지면처럼 세로로 긴 596 × 712에 -1.5도 돌려 놓았고(FE-50), 사진은 3:2를 유지한다. S-02와 같은 기준이다. 불러오기 전 · 실패 시에는 사건과 무관한 기본 문구를 둔다(책상은 그대로 동작).
- **그림은 CSS · 인라인 SVG로만 그린다** (이미지 파일 없음, 신문 사진만 사건 썸네일). 기준 좌표계 1672 × 941 안에 px로 놓고 화면 너비에 맞춰 통째로 줄인다(`--desk-scale`). **첫 화면은 어떤 크기에서도 책상만 꽉 찬다 (FE-87)**: 장면 높이 = 화면 높이(헤더 제외). 그림은 장면 안에 들어가게 줄이고 남는 쪽으로 책상을 늘린다. 소품 배치 순서(왼쪽 노트북 · 엽서 · 펜, 가운데 신문, 오른쪽 커피잔 · 서류철)는 어떤 크기에서도 같다. 넓은 화면은 패드 둘레 · 패드 · 물건 사이가 고르게 넓어지고(`--dx`), 높은 화면은 늘어난 높이를 먼저 신문이 흡수한다: 신문만 아래로 길어지고(`--ng`, 기본 높이의 1.2배까지, 늘어난 지면은 머리기사 사진 · 첫 문단 · 아래 기사 사진 · 기사 줄이 나눠 채움) 다른 물건은 비율을 바꾸지 않는다. 남는 높이(`--r`)는 나무 띠에 0.1씩, 나머지는 신문 · 서류철 위아래에 주고, 위 소품은 패드 윗변 · 아래 소품은 패드 아랫변에 붙는다. 남는 높이가 클수록(`--t`, 0 ~ 1) 소품을 모양 그대로 큼직하게 키우고(신문 1.3 · 노트북 1.4배) 신문 밖 소품은 조금 더 기울인다. 화면 폭이 좁아 책상이 작게 줄어들수록(`--u`, 배율 .85 → .5) 작은 소품을 더 키운다: 엽서와 펜 1.6 · 서류철 1.45 · 커피잔 1.75 · 내로 1.6배(둘 중 큰 쪽 `--k`). 포스트잇 · 내로는 패드 윗변 위 나무에 둔다(네이비 내로가 패드와 겹치지 않게). 커질수록 패드 윗변을 내린다. 포스트잇은 가장 먼저 눌러 보길 바라는 놀이라 기본 1.15배(최대 1.7배)로 크게 두고 신문 제호를 덮어도 된다. 책상에서 첫 Tab도 포스트잇이다. 노트북은 신문 쪽 모서리를, 서류철은 오른쪽 끝을 고정해 신문을 덮지 않는다. 아래 집무실은 늘 첫 화면 밖에서 시작한다. 720px 이하 메뉴 카드도 첫 화면을 채운다(메뉴는 가운데).
- **2D 평면 일러스트**라 물건이 들리거나 기우는 효과는 넣지 않는다(팀 결정). 마우스를 올리면 물건이 아주 살짝 밝아진다(`brightness(1.06)`, FE-50). 준비 중인 물건도 같다(커서만 기본 화살표).
- **신문 집어 들기 (FE-32, FE-50에서 바꿈)**: 신문을 누르면 신문이 책상에서 떠올라 살짝 기울고(0.38초) 바로 S-02로 간다. S-02 지면이 들린 기울기(-3도) 그대로 화면 아래에서 올라오며 서고(0.9초), 뒤에 남긴 책상은 그동안 흐려진다(`caseListPage.js`의 `.paper-ghost`, 성향 검사 서류철과 같은 방식). 움직임 줄이기면 바로 간다.
- **신문 내려놓기 (FE-32)**: 판결 체험 6막에서 "메인으로"(선택지 · 지면 맨 아래 버튼)를 누르면 보던 지면을 본뜬 한 장이 화면을 덮은 채 `navigate('landing', { from: 'paper' })`로 온다(`utils/paperHandoff.js`). 그 한 장이 제자리에서 줌아웃 · 페이드아웃을 함께(0.8초) 하며 책상이 드러난다. 새로고침 · 뒤로 가기로는 되풀이하지 않고, 움직임 줄이기면 연출 없이 바로 책상이다.
- **배치 (FE-50에서 좌우로 뒤집음)**: 왼쪽에 노트북 · 엽서(장식, 펜이 위에 걸쳐 놓임) · 펜(의견 보내기), 가운데 신문, 오른쪽에 커피잔 · 서류철. 그림 안의 글자는 뒤집지 않는다(서류철 SVG만 `scaleX(-1)`).
- **헤드라인은 책상 위에 없다 (FE-50).** 화면 제목(h1)은 낭독기용(`.visually-hidden`)으로만 남는다.
- 책상 위에 내로(가운데에서 살짝 오른쪽, 패드 윗변 위 나무 — FE-87)가 볼을 괴고 엎드려 있다(장식, `CHEEKS`, 오른쪽 끝에서 잰 px). 남불은 FE-87에서 아래 집무실 안내문 종이 밑으로 옮겼다. 컷은 원본 이미지 레포 PNG를 직접 읽는다(`shortcut:`).
- **내로는 포스트잇에 가려 있다 (FE-50, 놀이)**: "포스트잇을 제거해 귀여운 고양이를 구해주세요". 누르면 떼어져 날아가고(0.52초) 내로가 드러난다. 포커스는 바로 아래 신문으로 옮긴다(스크롤하지 않음). 화면을 다시 그리면 다시 붙어 있고, 움직임 줄이기면 바로 사라진다.
- **720px 이하**에서는 책상 대신 메뉴 카드(신문 → 서류철 · 커피잔 → 노트북)를 보여 준다.
- 아래에 **서비스 소개**(`#intro`)가 있다. 책상에서 카메라가 그대로 아래로 내려간 **판사의 집무실 바닥**이다(FE-87, 같은 2D 탑뷰 · 원근 없음). 위에서부터 책상 밑으로 쭉 밀어 넣은 넓은 1인용 판사 의자(방석 · 팔걸이는 책상에 가리고 등받이 · 팔걸이 끝만 보임, 책상 장면을 `z-index`로 위에 그림. 크기는 책상 소품과 같은 배율 `--desk-px`로 신문 폭 기준 · 가로는 그 1.6배, 가운데보다 오른쪽(`--chair-x` 60%)에서 등받이가 왼쪽 아래를 향하게 7도 틂) · 책상이 바닥에 드리운 그림자 → 의자 왼쪽 옆 · 왼쪽 벽에 붙은 바닥의 안내문(크기 · 자리는 고정이 아니라 화면에 따라 바뀐다: 폭은 책상 배율에 비례(최소 140px, 1440px 화면에서 약 330px), 왼쪽 벽에서 25 ~ 100px(넓을수록 시원하게), 책상 가장자리에서 최대 100px. 바닥에 붙은 종이라 자기 그림자는 짧고, 책상 그림자가 윗부분에 드리운다(제목은 그림자에 가리지 않게 종이 가운데). 놀이: 왼쪽 위 귀퉁이가 늘 들썩이고(`--curl` 1 ↔ 1.6, 마우스를 올리면 1.6 ↔ 3으로 더 크고 빠르게), 누르면 종이가 러그 쪽(거의 아래, 살짝 오른쪽)으로 러그 · 러그 위 서류 위를 지나 끌려가며 치워지고(`peelOff`, 시선이 러그로 이어짐. 치우는 동안 들썩임을 멈춰 잔상이 남지 않게 함) 밑에 숨어 있던 남불이 드러난다. 화면 제목 h2는 낭독기용으로 종이와 따로 두어 종이를 치워도 남는다. 의자는 방 폭의 62%에 두되 안내문과 최소 10px 떨어지도록 필요하면 오른쪽으로 밀리고, 좁은 화면에서는 의자 오른쪽이 벽 밖으로 잘린다. `container-type: inline-size` + `cqw`)(h2 "이렇게 체험해요"만 쓴 줄 칸 종이 한 장 — 설명은 러그가 한다) → 러그 위 서류 네 장 = 체험에서 내가 하는 일(체험 속 물건의 축소판, 설명은 한 줄): 뉴스만 본 나 = 책상 신문과 같은 머리기사 · 사진의 신문 스크랩 → 첫인상 = 징역형 / 벌금형 체크 칸 엽서 → 내 판결 = 판단 요소마다 무겁게 · 해당 없음 · 가볍게를 고른 파일철 → 모든 사실을 본 나 = 주문에 형량을 손으로 적고 확정 도장 찍은 판결문. 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래로 살짝 Z를 그리며 크게 겹쳐 흩어 놓은 순서가 곧 흐름. 넓은 화면에서 서류가 가로로만 길어지지 않게 서류 묶음 폭은 960px까지(러그 좌우는 비움) → 둥근 스툴 세 개 위 판결문 한 장씩 = 끝에 얻는 것(세 판결 비교 미리보기: 0 ~ 10년 형량 막대. 내 판결은 빈 "?", AI 판결은 점 · "징역 6년" 목데이터 표기 · 법률 자문 아님, 실제 판결은 흐리게 가리고 "맨 마지막에 공개" 봉인 띠. 스툴 · 종이 크기가 같아 대등, 러그 흐름을 이어 한 칸씩 내려가고 각도를 조금씩 다르게 틂, 좁은 화면은 좌우 지그재그. 아래 손글씨 메모 "셋을 나란히 놓으면, 어디서 갈렸는지 보여요". "세 판결을 나란히"는 바닥의 작은 꼬리표 종이) → 아래 벽의 열린 문이다. 문은 평면도 기호(벽 틈 · 90도 열린 문짝 · 점선 원호)로 그리고, 문틈으로 복도 불빛이 바닥에 길게 들어온다. 문 앞 발판이 사건 목록 버튼, 문 옆 바닥의 크라프트 서류철이 성향 테스트 버튼이다. 글자는 모두 바닥에 놓인 종이 · 발판 위에만 쓴다. 러그는 바닥에 깔린 천이라 떠 있는 그림자 없이 양 끝 술 · 직물 결로 그린다(액자처럼 보이지 않게, 실제 질감은 이미지 작업 후보). 720px 이하에서는 같은 방을 세로로 쌓는다(벽 10px, 서류는 폭 86%로 왼쪽 · 오른쪽을 오가며 겹침, 술은 위아래). `section: 'intro'`를 받으면 그 구역으로 스크롤한다(공통 헤더의 서비스 소개 탭은 FE-50에서, S-02 정보 줄의 "서비스 소개"는 FE-56에서 없앴다).

## 색 · 글꼴

- 색은 `src/style.css` ④의 `--color-desk-*` 역할 토큰과 공통 역할 토큰만 쓴다. 이 CSS에 색 값(hex · rgb)을 쓰지 않는다. 그림자 · 투명도는 `color-mix()`로 만든다.
- 포스트잇 손글씨는 `--font-hand`(나눔펜). `index.html` · `preview.html`의 글꼴 링크에 함께 있다.
- 공통 헤더 · 푸터는 [`components/siteLayout.js`](../../components/siteLayout.js)를 쓰고, 메인에서만 네이비 헤더 · 어두운 푸터로 바꾼다(`.landing-page .site-header` 등). 헤더는 화면 위에 고정되고(sticky), 메뉴는 사건 목록 · 성향검사 · 커뮤니티(FE-47) · 연출 스위치 · 로그인이다(FE-50).
- **연출은 책상 물건을 눌렀을 때만** 켜진다: 신문 · 서류철 · 커피잔은 `from` 표시(`desk` · `mug`)를 넘기고, 받는 화면이 그 표시가 있을 때만 연출한 뒤 지운다. 헤더 · 서비스 소개 버튼으로 가면 바로 바뀐다. 연출 스위치를 끄면 물건을 눌러도 바로 간다(`utils/motion.js`).
