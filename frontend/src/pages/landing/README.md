# landing

**S-01 메인 — 판사의 책상** 화면이다 (FE-18, 시안 "B안 일러스트 · C안 구도", 2D 평면).

| 파일 | 내용 |
| --- | --- |
| `landingPage.js` | `renderLandingPage(container, { api, navigate, section })` — 화면을 그린다 |
| `landing.css` | 메인 화면 스타일 (책상 일러스트 · 메뉴 카드 · 서비스 소개) |

## 구성

- **책상 위 물건이 메뉴다.** 이름표(메모지)는 붙이지 않는다(FE-50에서 없앴다). 물건 이름은 낭독기(`aria-label`)와 좁은 화면 메뉴 카드에 쓴다.

  | 물건 | 메뉴 | 이동 | 상태 |
  | --- | --- | --- | --- |
  | 신문 | 실제 사건 판결 체험 | 신문 집어 들기 → `navigate('list', { from: 'desk' })` → S-02 | 동작 |
  | 서류철 | 판결 성향 테스트 | 철이 화면 아래에서 올라옴 → `navigate('test', { from: 'desk' })` → S-15 | 동작 |
  | 커피잔 | 마이페이지 | 커다란 잔이 우상단에서 날아와 섰다가 오른쪽으로 빠져나감(`utils/coffeeDive.js`) → `navigate('me', { from: 'mug' })` → S-17 | 동작 |
  | 펜 | 의견 보내기 (FE-50, 휴대폰 자리) | 범위 밖 | 곧 열려요 |
  | 노트북 | 커뮤니티 | 범위 밖 | 곧 열려요 |

  화면이 생기면 `landingPage.js`의 `OBJECTS`에서 그 물건의 `route`에 화면 이름(`routes.js`의 `name`)만 넣는다. 누르기 가능 여부가 함께 바뀐다.
  책상 위 포스트잇은 내로를 가린 한 장(`--postit`, 접착면 띠)뿐이다. 서류철 그림 위 라벨은 "3분 성향검사".
- **신문 지면은 사건 목록 API(API 1)로 채운다.** 참여 많은 순 첫 사건이 머리기사(제목 · 부제 · 첫 문단 · 사진), 다음 2건이 아래 기사(S-02 추천 사건과 같은 사건 사진 16:9 → 제목 → 문단을 이어 4줄까지)다. 지면에는 이 3건만 싣고, 아래 기사 단은 지면 끝까지 내려가 가운데 세로 괘선이 길게 이어진다(남는 곳은 여백). 신문은 실제 지면처럼 세로로 긴 596 × 712에 -1.5도 돌려 놓았고(FE-50), 사진은 3:2를 유지한다. S-02와 같은 기준이다. 불러오기 전 · 실패 시에는 사건과 무관한 기본 문구를 둔다(책상은 그대로 동작).
- **그림은 CSS · 인라인 SVG로만 그린다** (이미지 파일 없음, 신문 사진만 사건 썸네일). 기준 좌표계 1672 × 941 안에 px로 놓고 화면 너비에 맞춰 통째로 줄인다(`--desk-scale`).
- **2D 평면 일러스트**라 물건이 들리거나 기우는 효과는 넣지 않는다(팀 결정). 마우스를 올리면 물건이 아주 살짝 밝아진다(`brightness(1.06)`, FE-50). 준비 중인 물건도 같다(커서만 기본 화살표).
- **신문 집어 들기 (FE-32, FE-50에서 바꿈)**: 신문을 누르면 신문이 책상에서 떠올라 살짝 기울고(0.38초) 바로 S-02로 간다. S-02 지면이 들린 기울기(-3도) 그대로 화면 아래에서 올라오며 서고(0.9초), 뒤에 남긴 책상은 그동안 흐려진다(`caseListPage.js`의 `.paper-ghost`, 성향 검사 서류철과 같은 방식). 움직임 줄이기면 바로 간다.
- **신문 내려놓기 (FE-32)**: 판결 체험 8막에서 "메인으로"(선택지 · 지면 맨 아래 버튼)를 누르면 보던 지면을 본뜬 한 장이 화면을 덮은 채 `navigate('landing', { from: 'paper' })`로 온다(`utils/paperHandoff.js`). 그 한 장이 제자리에서 줌아웃 · 페이드아웃을 함께(0.8초) 하며 책상이 드러난다. 새로고침 · 뒤로 가기로는 되풀이하지 않고, 움직임 줄이기면 연출 없이 바로 책상이다.
- **배치 (FE-50에서 좌우로 뒤집음)**: 왼쪽에 노트북 · 엽서(장식, 펜이 위에 걸쳐 놓임) · 펜(의견 보내기), 가운데 신문, 오른쪽에 커피잔 · 서류철. 그림 안의 글자는 뒤집지 않는다(서류철 SVG만 `scaleX(-1)`).
- **헤드라인은 책상 위에 없다 (FE-50).** 화면 제목(h1)은 낭독기용(`.visually-hidden`)으로만 남는다.
- 책상 위에 내로(가운데에서 살짝 오른쪽, 턱이 신문 위쪽 가장자리에 걸침) · 남불(펜 아래)이 볼을 괴고 엎드려 있다(장식, `CHEEKS`, 오른쪽 끝에서 잰 px). 컷은 원본 이미지 레포 PNG를 직접 읽는다(`shortcut:`).
- **내로는 포스트잇에 가려 있다 (FE-50, 놀이)**: "포스트잇을 제거해 귀여운 고양이를 구해주세요". 누르면 떼어져 날아가고(0.52초) 내로가 드러난다. 포커스는 바로 아래 신문으로 옮긴다(스크롤하지 않음). 화면을 다시 그리면 다시 붙어 있고, 움직임 줄이기면 바로 사라진다.
- **720px 이하**에서는 책상 대신 메뉴 카드(신문 → 서류철 · 커피잔 → 노트북)를 보여 준다.
- 아래에 **서비스 소개**(`#intro`)가 있다. 종이 한 장 위에 "뉴스만 본 나 → 첫인상 판단 → 최종 판결 → 모든 사실을 본 나"를 한 줄로 잇고(첫인상 전은 점선), 아래 단에 세 판결을 같은 모양으로 나란히 둔다. 버튼은 사건 목록 · 판결 성향 테스트 두 입구다 (FE-50). `section: 'intro'`를 받으면 그 구역으로 스크롤한다. S-02의 "서비스 소개"가 이 값을 넘긴다(공통 헤더의 서비스 소개 탭은 FE-50에서 없앴다).

## 색 · 글꼴

- 색은 `src/style.css` ④의 `--color-desk-*` 역할 토큰과 공통 역할 토큰만 쓴다. 이 CSS에 색 값(hex · rgb)을 쓰지 않는다. 그림자 · 투명도는 `color-mix()`로 만든다.
- 포스트잇 손글씨는 `--font-hand`(나눔펜). `index.html` · `preview.html`의 글꼴 링크에 함께 있다.
- 공통 헤더 · 푸터는 [`components/siteLayout.js`](../../components/siteLayout.js)를 쓰고, 메인에서만 네이비 헤더 · 어두운 푸터로 바꾼다(`.landing-page .site-header` 등). 헤더는 화면 위에 고정되고(sticky), 메뉴는 사건 목록 · 성향검사 · 커뮤니티(준비 중) · 연출 스위치 · 로그인이다(FE-50).
- **연출은 책상 물건을 눌렀을 때만** 켜진다: 신문 · 서류철 · 커피잔은 `from` 표시(`desk` · `mug`)를 넘기고, 받는 화면이 그 표시가 있을 때만 연출한 뒤 지운다. 헤더 · 서비스 소개 버튼으로 가면 바로 바뀐다. 연출 스위치를 끄면 물건을 눌러도 바로 간다(`utils/motion.js`).
